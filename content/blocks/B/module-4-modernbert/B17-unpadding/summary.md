## TL;DR

Unpadding: настоящие токены батча кладутся подряд в `[N, C]`, границы — в `cu_seqlens = [0, L₀, L₀+L₁, …, N]` (int32).
Линейные слои и FFN работают с упаковкой как есть. Attention получает блочно-диагональную маску (Flash Attention
`varlen` считает только блоки), RoPE — позиции с нуля у каждого текста. Экономия: $1 - \sum L/(BT)$ в линейных слоях
и $1 - \sum L^2/(BT^2)$ в attention. Ошибка на единицу в `cu_seqlens` склеивает соседние тексты.

## Формула

$$\text{cu} = [0, L_0, L_0{+}L_1, \dots, N];\quad \text{mask}[i,j] = [b(i) = b(j)];\quad \text{pos}_n = n - \text{cu}_{b(n)}$$

## Формы тензоров

```
mask [B,T] → indices [N], cu [B+1] · x [B,T,C] → pack [N,C] → q,k,v [N,H,D] → varlen attn → [N,H,D] → unpack [B,T,C]
```

## Что поменялось относительно B16

Слой тот же, меняется представление батча: вместо паддинга и маски PAD — упаковка, `cu_seqlens`, блочная маска и
позиции с нуля у каждого текста.
