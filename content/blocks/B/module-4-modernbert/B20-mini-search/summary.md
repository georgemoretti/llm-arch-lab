## TL;DR

Поиск по корпусу курса: 736 абзацев README, 298 вопросов курса для оценки. Bi-encoder (ModernBERT на 2 слоя, 0.5 М
параметров) обучается без разметки на inverse cloze task: кусок абзаца ↔ абзац без куска, InfoNCE с in-batch
негативами. Соперник — TF-IDF. За 1.5 минуты модель не обгоняет мешок слов (вопросы r@1 0.35 против 0.53), но гибрид
лучше обоих (0.55). Предобученная bge-m3 — лучшая на вопросах (0.61), но хуже TF-IDF на обрывках фраз. Обучение
снижает анизотропию: средний косинус случайных пар 0.18 → 0.03.

## Формула

$$\operatorname{idf} = \log\tfrac{1+N}{1+\operatorname{df}} + 1;\quad s_{\text{hybrid}} = \alpha\cos_{\text{bi}} + (1-\alpha)\cos_{\text{tfidf}};\quad \text{hit@}k = \operatorname{mean}_q[\text{top}_k \cap \text{gold} \ne \varnothing]$$

## Формы тензоров

```
ICT: q [B,Tq], d [B,Td] → ModernBERT → mean → L2 → [B,C] → InfoNCE;  поиск: D [N,C], Q [Q,C] → Q·Dᵀ [Q,N] → top-k
```

## Что поменялось относительно B19

Настоящие данные вместо синтетики, пары строятся из корпуса без разметки (ICT), энкодер — ModernBERT, оценка на
отложенных вопросах и сравнение с мешком слов.
