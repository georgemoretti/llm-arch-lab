# Отладка: перевод начинается правильно только у коротких фраз

## Зачем это нужно

Маски — главный источник тихих ошибок в энкодер-декодере: их три, у каждой своя форма и свой смысл. Ошибка в
маске не роняет код и не мешает лоссу падать. Модель просто учится переводить хуже, и это легко списать на
данные или гиперпараметры.

## Что поменялось относительно B04

Ничего: это те же функции, что в B04. Их написал кто-то другой, и в коде **одна** ошибка.

## Формула

Каждая позиция перевода может зависеть от **любого** настоящего токена источника:

$$
\frac{\partial\, \text{out}_t}{\partial\, \text{memory}_s} \ne 0
\quad \text{для всех } t \text{ и всех } s, \text{ где } \text{src}_s \ne \text{PAD}.
$$

## Формы тензоров

```shapes
y [B, T, C] — состояния декодера
memory [B, S, C] — выход энкодера
> cross-attention
weights [B, H, T, S]
out [B, T, C]
```

`causal_mask`, `target_mask` и `Decoder.forward` в порядке.

## Симптом

- causal-свойство декодера выполняется, маска цели верная;
- выход слоя не совпадает с `nn.TransformerDecoderLayer`, хотя веса те же;
- первая позиция цели не меняется, если изменить **последний** токен источника;
- при цели из 3 токенов и источнике из 6 изменение последнего токена источника не меняет **ни одной** позиции
  цели; при цели длиннее источника хвост цели его уже «видит».
