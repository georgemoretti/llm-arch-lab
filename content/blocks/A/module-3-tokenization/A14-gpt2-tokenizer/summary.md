## TL;DR

Токенизатор GPT-2 — это byte-level BPE из A11–A13 плюс два файла. `merges.txt` хранит 50 000 правил «a b» в
порядке обучения (номер строки = ранг), `vocab.json` — id каждой строки токена. Строки записаны через
`bytes_to_unicode` (пробел = `Ġ`). Внутри удобно работать в своих id (байт = id, правило k → 256 + k) и на
выходе переводить их в id GPT-2. Итог совпадает с библиотекой `tokenizers` токен в токен. 50 257 токенов =
256 байтов + 50 000 слияний + `<|endoftext|>`. Русский текст GPT-2 кодирует почти по байтам: больше
одного токена на символ.

## Формула

$$\text{merges}[(\operatorname{id}(a), \operatorname{id}(b))] = 256 + k,\quad \operatorname{id}(a\Vert b) = 256 + k,\quad \text{to\_gpt2}[\operatorname{id}(s)] = \text{vocab.json}[s]$$

## Формы тензоров

```
merges.txt [50 000 правил] + vocab.json [50 257] → merges, to_gpt2;  text → куски → свои id [n] → id GPT-2 [n]
```

## Что поменялось относительно A13

Слияния не обучаются, а читаются из файлов настоящей модели; появился перевод своих id в id GPT-2. Код
BPE остался тем же, и это проверка всего модуля: свой токенизатор равен эталонному.
