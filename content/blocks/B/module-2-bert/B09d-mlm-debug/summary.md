## TL;DR

`labels` посчитаны до того, как из выбранных позиций исключили спецтокены. Вход правильный (его строят по уже
исправленной маске), а цели содержат `[CLS]`, `[SEP]` и особенно PAD. Модель тратит часть лосса на тривиальное
«PAD → PAD», лосс падает подозрительно быстро. Порядок операций с масками важен: тензор, построенный по маске,
не меняется при последующей правке маски.

## Формула

$$\text{labels} = x \cdot [c \wedge \neg\,\text{special}] - 100 \cdot [\neg(c \wedge \neg\,\text{special})]$$

## Формы тензоров

```
chosen [B,T] → chosen &= ~special → labels [B,T], inputs [B,T]   (не labels до исключения)
```

## Что поменялось относительно B09

Ничего в механизме: найден неверный порядок двух строк. Его поймал тест «спецтокены не выбираются», который смотрит
на `labels`, а не только на вход.
