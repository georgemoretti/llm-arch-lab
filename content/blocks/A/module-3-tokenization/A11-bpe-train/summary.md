## TL;DR

Byte-level BPE стартует с 256 байтов и `vocab_size − 256` раз сливает самую частую пару соседних
токенов в новый токен с id `256 + k`. Результат обучения — упорядоченный список `merges`; номер слияния
служит его рангом. Неизвестных токенов не бывает: любой текст — байты UTF-8. На русском тексте первые
слияния собирают кириллические буквы из двух байтов, поэтому токен может быть половиной символа, и
словарь хранит `bytes`, а не `str`.

## Формула

$$(a,b)^* = \arg\max_{(a,b)} \operatorname{count}(a,b),\quad \text{ничья} \to \min(a,b);\qquad \text{merges}[(a,b)^*] = 256 + k$$

## Формы тензоров

```
text → bytes [n] → K раз: count_pairs → argmax → merge_pair → [n′ < n];  merges {(a,b): 256+k},  vocab {id: bytes} размера 256 + K
```

## Что поменялось относительно A10

Вместо фиксированного словаря символов — обучаемый словарь подслов поверх байтов. Он растёт на один
токен за слияние и укорачивает последовательность: на корпусе курса 120 слияний сжимают 42 тысячи
байтов почти втрое.
