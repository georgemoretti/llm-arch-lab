угол. Какие координаты образуют пару в раскладке «половинами»?

## Подсказка 3

`repeat_interleave(2)` превращает `[a, b, c, d]` в `[a, a, b, b, c, c, d, d]` — это раскладка для
интерливных пар (0-1, 2-3, …). Для пар (j, j + D/2) углы нужно склеить: `[a, b, c, d, a, b, c, d]`.
