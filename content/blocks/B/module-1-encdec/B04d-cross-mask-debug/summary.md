## TL;DR

Causal-маска в cross-attention — ошибка «по аналогии»: позиция $t$ цели видит только первые $t+1$ токенов
источника, хотя источник известен целиком. Модель всё равно учится, но начало перевода не знает конца фразы.
Маска cross-attention — только padding источника $[B, 1, 1, S]$; causal нужна лишь в self-attention декодера.

## Формула

$$M_{\text{cross}}[b, t, s] = [\text{src}_{b,s} \ne \text{PAD}]\quad(\text{а не } \wedge\ [s \le t])$$

## Формы тензоров

```
cross weights [B,H,T,S]: маска [B,1,1,S] (padding), без tril(T, S)
```

## Что поменялось относительно B04

Ничего в механизме: найдена лишняя causal-маска в cross-attention. Её поймал тест «первая позиция цели видит
последний токен источника».
