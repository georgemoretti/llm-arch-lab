# MLP на скалярах: нейрон, слой, обучение

## Зачем это нужно

У тебя есть `Value`, который умеет считать градиенты. Теперь из него можно собрать нейросеть и
обучить её. Многослойный перцептрон (MLP) — это сеть, на которой проще всего увидеть весь цикл
обучения:

1. **прямой проход** строит граф от входа до лосса;
2. **`loss.backward()`** раздаёт градиенты всем весам;
3. **шаг оптимизатора** сдвигает веса против градиента;
4. **обнуление градиентов** перед следующим шагом.

Тот же цикл ты будешь писать в A09 на тензорах и в блоке C для трансформеров. Меняется только
масштаб: вместо сотни `Value` там миллионы параметров в тензорах. FFN-блок трансформера — тоже MLP
(в C02 он станет SwiGLU).

## Что поменялось относительно A01

| | A01 | A03 |
|---|---|---|
| что строим | отдельные выражения | сеть из сотни параметров |
| кто вызывает backward | тест | цикл обучения |
| что делаем с градиентом | смотрим на него | шаг SGD: $\theta \leftarrow \theta - \eta\,\nabla\theta$ |
| новое | — | `parameters()`, `zero_grad`, лосс по батчу |

## Формула

Нейрон с весами $w \in \mathbb{R}^{n}$ и bias $b$:

$$
y = \tanh\Big(b + \sum_{i=1}^{n} w_i x_i\Big).
$$

Слой — это $m$ нейронов на одном и том же входе. MLP — цепочка слоёв, в которой выход одного слоя
служит входом следующего. В последнем слое tanh **нет**, иначе выход зажат в $(-1, 1)$.

Лосс по батчу из $N$ примеров и шаг градиентного спуска с learning rate $\eta$:

$$
L = \frac{1}{N}\sum_{k=1}^{N}\big(\hat y_k - y_k\big)^2,
\qquad
\theta \leftarrow \theta - \eta\,\frac{\partial L}{\partial \theta}.
$$

Почему без tanh нельзя: композиция линейных слоёв сама линейна, и такая сеть не отделит
внутреннее кольцо от внешнего. Именно эта задача стоит в тестах.

## Формы тензоров

Тензоров пока нет, всё на списках `Value`. Размеры для `MLP(2, [8, 1])`:

```shapes
x [2] — точка на плоскости (обычные числа)
> слой 1: 8 нейронов, у каждого 2 веса + bias; tanh
h [8] — список из 8 Value
> слой 2: 1 нейрон, 8 весов + bias; без tanh
ŷ [1] — список из одного Value
> MSE по всем примерам батча
L [] — один Value: loss.backward() → .grad у всех 33 параметров
```

`parameters()` возвращает параметры в фиксированном порядке: слой за слоем, нейрон за нейроном,
сначала веса, потом bias. Тесты по этому порядку переписывают веса в такую же сеть на torch.

## Задание

В `solution.py` (рабочая копия в `workspace/A03-mlp/`):

1. `Neuron.__call__` и `Neuron.parameters`, затем то же для `Layer` и `MLP`. `MLP` всегда
   возвращает **список** выходов последнего слоя.
2. `mse_loss(preds, ys)` — среднее квадратов разностей, результат `Value`.
3. `zero_grad(params)` и `sgd_step(params, lr)`. Меняй `.data` у тех же объектов.
4. `train(model, xs, ys, steps, lr)` — полный батч на каждом шаге; верни список `loss.data`.

Конструкторы готовы, их не меняй: веса берутся из генератора с фиксированным seed.

## Критерии готовности

- у `MLP(3, [4, 2])` ровно 26 параметров в документированном порядке, и это те же объекты;
- выход `MLP(3, [5, 4, 2])` совпадает с такой же сетью на torch, выходной слой линейный;
- `mse_loss` — среднее, градиент по предсказанию равен $2(\hat y - y)/N$;
- градиенты всех весов после `backward` совпадают с `torch.autograd`;
- `sgd_step` идёт против градиента, `zero_grad` обнуляет;
- `train` выучивает XOR (лосс < 0.05 за 200 шагов) и разделяет два кольца на 100% за 150 шагов.
