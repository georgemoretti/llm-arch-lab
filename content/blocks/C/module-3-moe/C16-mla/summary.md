## TL;DR

MLA сжимает K и V в общий латент: $c = \operatorname{norm}(W_{DKV} x)$ размера $r$ (у DeepSeek-V3 — 512), и в
кеше лежит только $c$; ключи и значения всех голов восстанавливаются как $W_{UK}^{(h)} c$, $W_{UV}^{(h)} c$. При
инференсе их можно вообще не восстанавливать: $q^\top W_{UK} c = (W_{UK}^\top q)^\top c$ — $W_{UK}$ поглощается в
запрос, $W_{UV}$ — в выход, attention идёт по латентам. В отличие от GQA/MQA головы не выбрасываются, а сжимаются;
по отчёту DeepSeek-V2 качество не хуже MHA.

## Формула

$$c = \operatorname{norm}(W_{DKV}x),\quad k_h = W_{UK}^{(h)}c,\quad v_h = W_{UV}^{(h)}c,\quad
q_h^\top k_h = (W_{UK}^{(h)\top} q_h)^\top c$$

## Формы тензоров

```
c [B,S,r] (кеш) → kv_b_proj → [B,H,S,d+dv] → k, v;  поглощённо: q_lat [B,H,T,r] · cᵀ → [B,H,T,S] → o_lat [B,H,T,r] → [B,H,T,dv]
```

## Что поменялось относительно C05

Кеш хранит $r$ чисел на токен вместо $2 H_{kv} d$; K и V восстанавливаются (или поглощаются) из латента.
Позиционного кодирования здесь нет — RoPE ломает поглощение, его добавляют отдельной частью головы (C16b).
