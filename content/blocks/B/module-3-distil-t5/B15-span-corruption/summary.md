## TL;DR

Предобучение T5: в тексте 15 % токенов — шум, разбитый на спаны со средней длиной 3. Во входе каждый спан заменён
одним sentinel (`<extra_id_0>` = 32 099, дальше по убыванию), цель — те же sentinel-ы, за каждым вырезанный кусок,
в конце EOS. Вход короче текста, цель — около 15 % его длины, поэтому обучение дешевле, чем восстановление всего
текста. Маска строится честным случайным разбиением: ровно round(0.15·L) токенов в round(·/3) спанах, текст и шум
чередуются, первым идёт текст. Цель — та же операция над инвертированной маской.

## Формула

$$|\text{вход}| = L - n_{\text{noise}} + n_{\text{spans}} + 1,\quad |\text{цель}| = n_{\text{noise}} + n_{\text{text spans}} + 1;\quad L = 568 \Rightarrow 512$$

## Формы тензоров

```
ids [L] → noise_mask [L] → inputs [L − n + k + 1], targets [n + k' + 1]
```

## Что поменялось относительно B09

Закрываются не токены, а спаны; один sentinel на спан вместо [MASK] на каждый токен; цель — отдельная короткая
последовательность для декодера, а не labels той же длины; нет 80 / 10 / 10.
