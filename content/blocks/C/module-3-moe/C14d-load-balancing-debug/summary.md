## TL;DR

Bias-балансировка DeepSeek-V3 — отрицательная обратная связь: перегруженный эксперт получает
меньший bias и реже выбирается. Ошибка знака превращает её в положительную: нагрузка не
выравнивается, а расходится до «мёртвых» экспертов. Проверять такие механизмы нужно симуляцией
нескольких сотен шагов, а не одним вызовом.

## Формула

$$b_i \leftarrow b_i - \gamma\,\operatorname{sign}(\text{load}_i - \overline{\text{load}})\quad(\text{не } +\gamma)$$

## Формы тензоров

```
load [E], bias [E] → bias − γ·sign(load − mean) [E]
```

## Что поменялось относительно C14

Ничего в архитектуре: это C14 с перевёрнутым знаком шага bias. Урок — тестировать обратную связь в
динамике.
