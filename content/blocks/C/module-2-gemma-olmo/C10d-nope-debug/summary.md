## TL;DR

В моделях с неоднородными слоями (RoPE/NoPE, sliding/full) ошибка в расписании не ломает ни формы,
ни загрузку весов — у слоёв одинаковые параметры. Число особых слоёв может совпасть, а места — нет:
`i % k == 0` (первый в группе) вместо `(i + 1) % k == 0` (последний). Лечится сверкой расписания с
`config.json` (`no_rope_layers` у SmolLM3, `layer_types` у Gemma).

## Формула

$$\text{слой } i \text{ — NoPE} \iff (i + 1) \bmod \text{interval} = 0 \quad(\text{а не } i \bmod \text{interval} = 0)$$

## Формы тензоров

```
rope_layers(36, 4) = [T, T, T, F] × 9 ;  неверно: [F, T, T, T] × 9
```

## Что поменялось относительно C10

Ничего в архитектуре: это C10 с расписанием, сдвинутым на один слой. Урок — проверять расписание
слоёв по config.json, а не только число особых слоёв.
