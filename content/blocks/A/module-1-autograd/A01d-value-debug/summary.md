## TL;DR

Если в обратном проходе вклад записывается через `child.grad = …`, а не прибавляется через `+=`,
то узел с несколькими потребителями получает только последний вклад. Графы-цепочки при этом
считаются верно, ошибаются только графы с ветвлениями. Поэтому проверять градиенты нужно на
выражениях, где один вход используется в нескольких местах.

## Формула

$$\frac{\partial L}{\partial v} = \sum_{u} \frac{\partial L}{\partial u}\,\frac{\partial u}{\partial v}\quad(\text{сумма, а не последний член})$$

## Формы тензоров

```
скаляры; ошибка проявляется только на узлах с ≥ 2 потребителями (x·x, a·b + a)
```

Ничего в механизме: найдена и исправлена ошибка накопления градиента.
