## TL;DR

WordPiece кодирует слово жадно: с начала берётся самый длинный кусок из словаря, продолжения ищутся с префиксом
`##`, неразбираемое слово целиком становится `[UNK]`. До этого текст очищается, у uncased-моделей переводится в
нижний регистр и теряет диакритику (NFD без знаков Mn — у русского исчезает «й»), режется по пробелам и по каждому
знаку пунктуации. `##` сохраняет границы слов: видно, какие токены — начала слов. Словарь `bert-base-uncased` —
30 522 токена, английский; русский текст в нём разбирается почти по буквам.

## Формула

$$p_k = \text{самый длинный } u: \ (\#\#)u \in V,\ \text{остаток слова начинается с } u$$

## Формы тензоров

```
текст → clean → lower → strip_accents → слова (пробелы, пунктуация) → wordpiece → токены [N]
```

## Что поменялось относительно A12

Вместо слияний по рангам (BPE) — жадный поиск самого длинного куска по словарю; вместо байтов — символы
Unicode с нормализацией; появились `##` и `[UNK]`.
