# Value: autograd на скалярах

## Зачем это нужно

Обучение нейросети — это спуск по градиенту: нужно знать, как лосс меняется при небольшом сдвиге
каждого из миллионов параметров. Выписывать производную руками для каждой новой архитектуры
невозможно. Поэтому во всех фреймворках есть **autograd**: во время прямого прохода он запоминает,
какие операции над какими числами выполнялись, а потом одним обратным проходом считает производную
выхода по всем входам сразу.

В этой задаче ты напишешь такой механизм для отдельных чисел (скаляров). Он работает так же, как
`loss.backward()` в PyTorch, только без тензоров. Когда в A04 и в блоке C ты будешь вызывать
`backward()`, ты будешь понимать, что происходит внутри.

## Что поменялось относительно ручного дифференцирования

| | вручную | autograd |
|---|---|---|
| что пишет человек | формулу производной для каждой функции | только прямой проход |
| что нужно знать про операцию | производную всей функции | локальные производные одной операции |
| составные функции | chain rule на бумаге | chain rule в цикле по графу |
| стоимость градиента по N входам | N выводов формул | один обратный проход ≈ стоимость прямого |

## Формула

Каждая операция знает только свои **локальные** производные. Например, для $c = a \cdot b$ это
$\partial c / \partial a = b$ и $\partial c / \partial b = a$. Производную выхода $L$ по любому
узлу даёт chain rule. Если узел $v$ используется несколькими операциями (потребителями) $u_1, \dots, u_m$, их вклады **складываются**:

$$
\frac{\partial L}{\partial v} \;=\; \sum_{j=1}^{m} \frac{\partial L}{\partial u_j}\cdot\frac{\partial u_j}{\partial v},
\qquad \frac{\partial L}{\partial L} = 1.
$$

Чтобы взять $\partial L / \partial u_j$ уже готовым, узлы обходят **от выхода ко входам**:
каждый узел обрабатывается после всех своих потребителей. Это обратный топологический порядок
графа.

Локальные производные примитивов:

| операция | значение | локальные производные |
|---|---|---|
| `a + b` | $a + b$ | $1,\ 1$ |
| `a * b` | $ab$ | $b,\ a$ |
| `x ** k` | $x^k$ | $k\,x^{k-1}$ |
| `x.exp()` | $e^x$ | $e^x$ |
| `x.log()` | $\ln x$ | $1/x$ |
| `x.tanh()` | $t = \tanh x$ | $1 - t^2$ |
| `x.relu()` | $\max(0, x)$ | $1$ при $x > 0$, иначе $0$ |

Вычитание и деление отдельных производных не требуют, они выражаются через примитивы:
$a - b = a + (-1)\cdot b$ и $a / b = a \cdot b^{-1}$.

## Формы тензоров

Тензоров здесь нет, все величины скалярные. Зато важно, как устроен граф. Возьмём нейрон
$L = \tanh(w x + b)$:

```shapes
x [] — вход
w [] — вес
> w * x — локальные производные: ∂/∂w = x, ∂/∂x = w
wx []
> + b — ∂/∂wx = 1, ∂/∂b = 1
z []
> tanh — ∂L/∂z = 1 − tanh²(z)
L [] — backward: L.grad = 1, дальше от выхода ко входам
```

Каждый `Value` хранит своё значение `data`, градиент `grad`, входы `_children` и локальные
производные `_local_grads`. Значит, каждый узел хранит рёбра к своим входам вместе с производными.

## Задание

В `solution.py` (рабочая копия в `workspace/A01-value/`) допиши класс `Value`:

1. Примитивы `__add__`, `__mul__`, `__pow__`, `exp`, `log`, `tanh`, `relu`. Каждый возвращает
   новый `Value(значение, (входы…), (локальные производные…), "имя")`.
2. `backward()`: топологическая сортировка графа **без рекурсии** (на явном стеке), затем
   `self.grad = 1` и проход от выхода ко входам.

Конструктор, `__repr__` и производные операции (`-x`, `a - b`, `a / b`, `2 * x` …) уже написаны.
Их не меняй. Ни torch, ни другие библиотеки не нужны: хватит модуля `math`.

## Критерии готовности

- `a·b + a` даёт правильное значение и градиенты: каждый вход умножения получает значение
  другого входа;
- все унарные операции (exp, log, tanh, relu, степени 3, −1, 0.5) совпадают с `torch.autograd`;
- работают выражения с обычными числами с обеих сторон: `2 * x`, `1 - x`, `3 / x`;
- узел, который используется несколько раз, получает **сумму** вкладов (`x·x + x` → `2x + 1`);
- после `backward()` у выхода `grad = 1`, а узлы вне графа не трогаются;
- в графе с общими подвыражениями градиенты совпадают с torch. Это проверяет порядок обхода;
- четыре составных выражения (нейрон, деление, exp/log/tanh вперемешку) совпадают с torch;
- цепочка из 5000 операций (10 000 узлов) проходит без `RecursionError` быстрее чем за секунду.
