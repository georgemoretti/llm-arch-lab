## TL;DR

Дистилляция учит маленькую модель повторять распределение большой. Логиты обоих делят на температуру T (у
DistilBERT T = 2): распределение учителя становится площе, и ученик видит, какие неправильные ответы учитель считает
похожими на правильный. Лосс — T²·KL(p_учителя ‖ q_ученика): множитель T² держит масштаб градиента T·(q − p)/N
постоянным при любой T. Смесь с обычной CE по меткам, у DistilBERT ещё и 1 − cos между скрытыми состояниями
(веса 5 : 2 : 1). Ученик DistilBERT — 6 слоёв, скопированных из 12 слоёв BERT через один: 66 М параметров, 97 %
качества на GLUE.

## Формула

$$\mathcal{L} = \alpha\,T^2\,\mathrm{KL}\big(\operatorname{softmax}(v/T)\,\|\,\operatorname{softmax}(z/T)\big) + (1 - \alpha)\operatorname{CE}(z, y),\quad \nabla_z = \tfrac{T}{N}(q - p)$$

## Формы тензоров

```
логиты [B,T,V] → [N,V] → p, q → KL по V, mean по N, ×T²;  h [B,T,H] → [N,H] по mask → 1 − cos
```

## Что поменялось относительно B10

Модель та же (BertForMaskedLM), меняется обучение: цель — распределение учителя на всех токенах плюс MLM, слоёв вдвое
меньше, инициализация из слоёв учителя, учитель заморожен.
