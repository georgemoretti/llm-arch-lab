# Квиз модуля: Обучение нейросети

## Зачем это нужно

Вопросы про оптимизаторы, расписания и отладку обучения задают почти на каждом ML-собеседовании. Квиз
собирает их по всему модулю: инициализация, SGD, Adam и AdamW, warmup и clipping, порядок шага обучения,
языковая модель и перплексия. Сюда же входят вопросы с твоих собеседований на эти темы.

## Что ты построил в модуле — в одной таблице

| идея | где | что запомнить |
|---|---|---|
| масштаб инициализации | A06 | $\operatorname{Var}(w) = \text{gain}^2/\text{fan\_in}$, у ReLU gain = $\sqrt2$ |
| momentum | A07 | гасит колебания поперёк оврага, разгоняет вдоль |
| Adam | A07 | $\hat m/\sqrt{\hat v}$, bias correction, шаг ≈ lr на координату |
| AdamW | A07, A07d | decay отдельно от градиента: $\theta(1 - \eta\lambda)$ |
| warmup + cosine | A08 | lr от $\eta_{\max}/W$ до $\eta_{\max}$, затем косинус до $\eta_{\min}$ |
| clipping | A08 | одна глобальная норма, направление сохраняется |
| порядок шага | A09, A09d | lr → batch → zero_grad → backward → clip → step |
| eval-режим | A09 | dropout выключен, no_grad, вернуть train |
| перплексия | A10 | $e^{\text{CE}}$; у равных логитов она равна $V$ |

## Как проходить

1. Открой вкладку **«Вопросы»**.
2. В вопросах с вариантами выбери ответ: сразу будет видно, верен ли он, и объяснение.
3. На открытые вопросы сначала ответь сам (2–4 предложения), затем открой эталон и честно оцени ответ.
4. Если ответил неуверенно, вернись к задаче из таблицы. Её конспект лежит во вкладке «Конспекты».

Оценки попадают в интервальное повторение (SM-2) во вкладке **Interview**.
