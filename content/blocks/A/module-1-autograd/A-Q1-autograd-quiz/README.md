# Квиз модуля: Autograd

## Зачем это нужно

Написать backward и объяснить его на собеседовании — разные навыки. Квиз собирает вопросы по всему
модулю: граф вычислений и накопление градиентов, проверку конечными разностями, цикл обучения,
softmax + cross-entropy и backward LayerNorm. Часть вопросов с выбором ответа, на остальные отвечай
своими словами и сравнивай с эталоном.

## Что ты построил в модуле — в одной таблице

Проверь, что можешь объяснить каждую строку, не подглядывая в задачи.

| идея | где | что запомнить |
|---|---|---|
| граф и локальные производные | A01 | прямой проход записывает, обратный применяет chain rule |
| накопление градиента | A01d | вклады нескольких потребителей складываются (`+=`) |
| обратный топологический порядок | A01 | узел отдаёт градиент только когда он полный |
| проверка градиентов | A02 | центральная разность, float64, h ≈ 1e-5, относительная ошибка |
| цикл обучения | A03 | forward → loss → zero_grad → backward → step |
| backward на тензорах | A04 | `dW = dyᵀx`, `db = Σ dy` — сверка по формам |
| softmax + CE | A04, A04d | градиент `p − y`, вычитание максимума |
| статистики в backward | A05 | пути через μ и σ, `Σ dx = 0` |

## Как проходить

1. Открой вкладку **«Вопросы»**.
2. В вопросах с вариантами выбери ответ: сразу будет видно, верен ли он, и объяснение.
3. На открытые вопросы сначала ответь сам (лучше письменно, 2–4 предложения), затем открой эталон и
   честно оцени, всё ли главное ты назвал.
4. Если ответил неуверенно, вернись к задаче из таблицы. Её конспект лежит во вкладке «Конспекты».

Оценки попадают в интервальное повторение (SM-2) во вкладке **Interview**. Там же есть режим «квиз по модулю».
