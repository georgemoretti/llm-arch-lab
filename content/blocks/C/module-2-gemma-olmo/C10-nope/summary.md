## TL;DR

NoPE — attention-слой без позиционного кодирования: тот же GQA, но q и k не поворачиваются. Декодеру
это не смертельно: causal-маска сама несёт позицию (запрос на позиции t видит t + 1 ключей, веса
softmax зависят от t). Для последнего токена NoPE-слой — «мешок слов» (порядок предыдущих не важен),
поэтому RoPE оставляют в большинстве слоёв. SmolLM3: каждый 4-й слой (3, 7, …, 35 из 36) — NoPE;
по словам авторов, это помогает длинному контексту, не вредя короткому.

## Формула

$$\text{RoPE: } (R_i q_i)\cdot(R_j k_j)/\sqrt{D},\qquad \text{NoPE: } q_i \cdot k_j/\sqrt{D},\qquad
\text{слой } i \text{ NoPE} \iff (i + 1) \bmod \text{interval} = 0$$

## Формы тензоров

```
q [B,H,T,D], k [B,H_kv,T,D] → (RoPE, если use_rope) → scores [B,H,T,T] + causal → out [B,T,C]
```

## Что поменялось относительно C05

Флаг `use_rope` у слоя и расписание слоёв: RoPE больше не «свойство модели», а свойство слоя.
Маска остаётся везде. Новых параметров нет.
