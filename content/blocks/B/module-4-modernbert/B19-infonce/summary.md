## TL;DR

InfoNCE: матрица $\hat Q \hat D^\top/\tau$ — логиты, запрос $i$ «классифицирует» свой документ $i$ среди всех документов
батча (in-batch негативы, плюс hard negatives `d[N:]`), лосс — cross-entropy по строкам. Градиент $(p - \text{onehot})d/(\tau N)$
тянет к позитиву и отталкивает от негативов пропорционально вероятности перепутать. Температура (E5: 0.01,
SimCSE: 0.05) растягивает косинусы из $[-1, 1]$, иначе softmax почти равномерный. Больше батч — больше негативов
(E5: 32K). Симметричный вариант добавляет CE по столбцам. Метрика — recall@k.

## Формула

$$\mathcal L = \operatorname{CE}(\hat Q\hat D^\top/\tau,\ \operatorname{arange}(N)),\quad \mathcal L_{\text{sym}} = \tfrac12[\operatorname{CE}(S, y) + \operatorname{CE}(S^\top, y)]$$

## Формы тензоров

```
q [N,C], d [M,C] → logits [N,M] → CE(labels 0…N−1) → [];  scores [N,M] → topk [N,k] → recall
```

## Что поменялось относительно B18

Эмбеддинги не только используются, но и обучаются: матрица косинусов становится логитами классификации «свой
документ среди батча».
