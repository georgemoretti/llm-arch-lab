## TL;DR

Мини-GPT = эмбеддинги токенов и позиций (A15) → `n_layer` pre-LN блоков с одноголовым causal attention и
MLP (A16, A17) → финальный LayerNorm → выходной слой, связанный с эмбеддингами. Обучение на случайных
кусках текста: `y` — `x` со сдвигом на 1, каждый кусок даёт `T` предсказаний. Генерация: последние
`block_size` токенов → логиты последней позиции / τ → сэмпл → дописать. На корпусе курса (21 тыс.
символов обучения) модель на 190 тыс. параметров достигает val ≈ 2.25 к ~1000-му шагу, дальше
переобучается. Отсюда ранняя остановка.

## Формула

$$\text{logits} = \operatorname{LN}_f\big(\operatorname{Block}_L \circ \dots \circ \operatorname{Block}_1 (E_x + P)\big) E^{\top},\qquad x_{t+1} \sim \operatorname{softmax}(\text{logits}_t / \tau)$$

## Формы тензоров

```
data [N] → x, y [B,T] → emb [B,T,C] → L × Block → ln_f → logits [B,T,V] → CE;  generate: idx[:, −block:] → logits[:, −1] → +1 токен
```

## Что поменялось относительно A10

Окно из 4 символов заменено attention на всю последовательность до `block_size`, один скрытый слой —
стопкой блоков с остатками и нормализацией. Это уже GPT: от GPT-2 её отличают число голов, BPE-словарь
и размеры.
