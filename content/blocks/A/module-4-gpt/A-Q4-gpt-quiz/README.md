# Квиз модуля: Свой GPT

## Зачем это нужно

«Объясни self-attention», «зачем делить на √d», «что такое causal-маска», «pre-LN или post-LN» — эти
вопросы звучат почти на каждом собеседовании по LLM. Ты только что ответил на них кодом. Квиз проверяет,
что ответ получается и словами. В квиз входят вопросы модуля и вопросы с твоих собеседований про attention,
позиции, архитектуру трансформера и генерацию.

## Что ты построил в модуле — в одной таблице

| идея | где | что запомнить |
|---|---|---|
| позиционные эмбеддинги | A15 | `wte(idx) + wpe(arange T)`; позиций не больше `block_size` |
| weight tying | A15 | `lm_head.weight = wte.weight`, градиенты двух путей складываются |
| стартовый loss | A15, A18 | $\approx \ln V$ при малых весах |
| scaled dot-product | A16 | $\operatorname{softmax}(QK^\top/\sqrt D + M)V$ |
| causal-маска | A16, A16d | $-\infty$ до softmax; после softmax будущее протекает через знаменатель |
| остатки | A17 | $x + f(\cdot)$: тождество при нулевых подслоях, градиент без затухания |
| pre-LN и post-LN | A17 | $x + f(\operatorname{LN} x)$ против $\operatorname{LN}(x + f(x))$ |
| MLP | A17 | $C \to 4C \to$ GELU(tanh) $\to C$ |
| батчи GPT | A18 | `y` = `x` со сдвигом на 1, кусок даёт $T$ примеров |
| генерация | A18 | последние `block_size` токенов → логиты последней позиции / τ → сэмпл |
| переобучение | A18 | val растёт при падающем train; ранняя остановка |

## Как проходить

1. Открой вкладку **«Вопросы»**.
2. В вопросах с вариантами выбери ответ: сразу будет видно, верен ли он, и объяснение.
3. На открытые вопросы сначала ответь сам (2–4 предложения), затем открой эталон и честно оцени ответ.
4. Если ответил неуверенно, вернись к задаче из таблицы. Её конспект лежит во вкладке «Конспекты».

Оценки попадают в интервальное повторение (SM-2) во вкладке **Interview**. Итоговый квиз по всему блоку A —
