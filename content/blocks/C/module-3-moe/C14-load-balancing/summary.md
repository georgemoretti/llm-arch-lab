## TL;DR

Без балансировки роутер MoE схлопывается: несколько экспертов получают почти все токены. Aux loss
(Switch, Mixtral, OLMoE, Qwen3): $L = E \sum_i f_i P_i$, где $f_i$ — доля назначений (счётчик, без
градиента), $P_i$ — средняя вероятность; при балансе 1, при коллапсе $E$; добавляется с малым
коэффициентом (0.001–0.02). DeepSeek-V3 почти без aux loss: bias к оценкам экспертов влияет только на
выбор top-k и после каждого шага сдвигается на ±γ против перекоса нагрузки — веса выходов при этом
из исходных оценок, градиент основного loss не искажается.

## Формула

$$L_{\text{aux}} = E\sum_i f_i P_i,\qquad \mathcal{T} = \operatorname{top-}k(s + b),\qquad
b_i \leftarrow b_i - \gamma\,\operatorname{sign}(\text{load}_i - \overline{\text{load}})$$

## Формы тензоров

```
router_logits [N,E] → probs [N,E] → f [E] (bincount top-k), P [E] (mean) → L []
scores [N,E] + bias [E] → indices [N,k];  weights = scores.gather(indices)
```

## Что поменялось относительно C13

MoE-слой не меняется — меняется обучение роутера: либо дополнительный loss по логитам, которые
возвращает слой, либо bias, сдвигающий выбор экспертов вне градиентного спуска.
