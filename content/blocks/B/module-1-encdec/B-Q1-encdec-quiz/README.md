# Квиз модуля: Transformer — энкодер и декодер

## Зачем это нужно

«Чем энкодер отличается от декодера», «какие маски где стоят», «что такое teacher forcing», «зачем label
smoothing» — классические вопросы собеседований, особенно на позиции, где работают с переводом, суммаризацией и
T5-подобными моделями. Ты ответил на них кодом. Квиз проверяет, что ответ получается и словами. В квиз входят
вопросы модуля и вопросы с твоих собеседований про архитектуру трансформера, multi-head и позиции.

## Что ты построил в модуле — в одной таблице

| идея | где | что запомнить |
|---|---|---|
| padding-маска | B01 | запрещает PAD-**ключи** $[B, 1, 1, S]$; True в PyTorch `key_padding_mask` — наоборот |
| multi-head | B01, B01d | `view(B, L, H, D).transpose(1, 2)`; при $H = 1$ ошибка нарезки не видна |
| синусоиды | B02 | $\sin / \cos(p\,\omega_i)$, $\omega_i = 10000^{-2i/C}$; сдвиг — поворот; токены $\times\sqrt C$ |
| слой энкодера | B03 | двунаправленный, Post-LN: $\operatorname{LN}(x + f(x))$, ReLU-FFN |
| слой декодера | B04 | causal self → cross (Q из декодера, K/V из памяти) → FFN |
| маски | B04, B04d | энкодер: padding; декодер: causal & padding; cross: только padding источника |
| teacher forcing | B05, B05d | вход `[BOS, y0 …]`, цель `[y0 …]`; не `torch.roll` |
| label smoothing | B05 | $q = (1-\varepsilon)\,\text{one-hot} + \varepsilon/V$, градиент $p - q$ |
| генерация | B05 | энкодер один раз; argmax последней позиции; PAD после EOS |
| проект | B06 | 2000 примеров → 99 % на отложенных; выравнивание в cross-attention; сдвиг распределения |

## Как проходить

1. Открой вкладку **«Вопросы»**.
2. В вопросах с вариантами выбери ответ: сразу будет видно, верен ли он, и объяснение.
3. На открытые вопросы сначала ответь сам (2–4 предложения), затем открой эталон и честно оцени ответ.
4. Если ответил неуверенно, вернись к задаче из таблицы. Её конспект лежит во вкладке «Конспекты».

Оценки попадают в интервальное повторение (SM-2) во вкладке **Interview**. Следующий модуль — BERT: тот же
энкодер, но без декодера и с новой задачей предобучения.
