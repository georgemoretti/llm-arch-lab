# Сырая база вопросов с собеседований

Клади сюда свои вопросы как есть: .md, .txt, .csv, .json, .xlsx, несколько файлов — всё подойдёт.
Ничего размечать вручную не нужно.

Агент (Фаза 7, запускается через `/next`) сам разберёт формат, уберёт дубли, переведёт
вопросы в `content/questions/*.yaml` и привяжет их к задачам курса. Если файлы появятся здесь
до начала контентных фаз, импорт выполнится раньше, и квизы сразу будут на твоих вопросах.

Импорт вручную (если добавил файлы позже):

```bash
llmlab questions import      # разобрать и убрать точные дубли (результат — в .llmlab/, не в git)
llmlab questions status      # сколько уже размечено в content/questions/interview-*.yaml
llmlab questions batch       # следующая неразмеченная пачка — отдай её агенту на разметку
```

Подробности — `docs/QUESTIONS_IMPORT.md`. Вопросы появятся во вкладке **Interview**.
