## TL;DR

Гибридный стек чередует дешёвые линейные слои (Gated DeltaNet, состояние фиксированного размера) с редкими full
attention слоями (точное извлечение). Qwen3-Next: 48 слоёв, каждый 4-й — gated attention ($(i+1) \bmod 4 = 0$),
36 — Gated DeltaNet. Память инференса = KV-cache только 12 full-слоёв + 36 константных состояний: на длинном
контексте → ¼ от «все full», выигрыш начинается после $H_{\text{lin}} d_k d_v / (2H_{kv}d) = 512$ токенов. Блок — обычный
Pre-Norm, меняется только mixer.

## Формула

$$M(S) = b\big(N_{\text{full}}\cdot 2H_{kv}d\cdot S + N_{\text{lin}}\cdot H_{\text{lin}}d_kd_v\big),\qquad \text{full} \iff (i+1) \bmod n = 0$$

## Формы тензоров

```
x [B,T,C] → [norm → GatedDeltaNet → +, norm → FFN → +] ×3 → [norm → GatedAttention → +, norm → FFN → +] → … → norm
```

## Что поменялось относительно C11

Вместо sliding-слоёв с кешем $\min(S, W)$ — линейные слои с константным состоянием, которые видят всё прошлое
(приблизительно). Соотношение 3 : 1 вместо 5 : 1; память → ¼ вместо ⅙, но без «слепоты» за окном.
