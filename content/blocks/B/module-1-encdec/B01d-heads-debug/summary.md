## TL;DR

`x.view(B, H, L, D)` вместо `x.view(B, L, H, D).transpose(1, 2)` даёт правильную форму, но перемешивает позиции
между головами: голова получает куски векторов **разных** позиций, а padding-маска по ключам закрывает не те
элементы. С одной головой ошибка не видна, потому что при $H = 1$ оба варианта совпадают. Ловят её свойства:
совпадение с эталоном при $H > 1$, эквивариантность к перестановке, независимость от содержимого PAD.

## Формула

$$\text{голова } h \text{ позиции } l = x_{l,\; hD : (h+1)D}\qquad(\text{а не кусок плоского массива } x_{hLD + lD : \dots})$$

## Формы тензоров

```
[B, L, C] → view(B, L, H, D) → transpose(1, 2) → [B, H, L, D]   (не view(B, H, L, D))
```

## Что поменялось относительно B01

Ничего в механизме: найдена неверная нарезка голов. Её поймали эквивариантность и padding-инвариантность.
