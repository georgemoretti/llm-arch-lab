## TL;DR

В Pre-Norm через норму проходит только вход подслоя: `x = x + f(norm(x))`. Если написать
`h = norm(x); x = h + f(h)`, остаточный поток нормируется в каждом блоке: блок с нулевыми
подслоями перестаёт быть тождественным, обученные веса не подходят, а градиент по остаточному
пути больше не идёт «напрямую». Проверка — свойство «нулевые подслои → блок = identity».

## Формула

$$\text{верно: } x + f(\operatorname{norm}(x)) \qquad \text{ошибка: } \operatorname{norm}(x) + f(\operatorname{norm}(x))$$

## Формы тензоров

```
x [B,T,C] → norm → f → [B,T,C];  прибавляется к x, а не к norm(x)
```

## Что поменялось относительно C06

Ничего в архитектуре: это C06, где остаток берётся от нормированного входа. Урок — проверять
сборку блока свойствами (identity при нулевых подслоях), а не только совпадением форм.
