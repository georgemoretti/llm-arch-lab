## TL;DR

T5 не добавляет позиции к эмбеддингам. В каждую голову к scores прибавляется обучаемый скаляр $B[\text{bucket}(j - i), h]$:
он зависит только от сдвига ключа относительно запроса. Бакеты: половина — точные расстояния (0 … 7 при 32
бакетах), половина — логарифмические корзины до max_distance = 128, всё дальнее — в последнем. В энкодере бакеты
делятся на «слева» и «справа», в декодере все отданы прошлому. Таблица `[32, H]` есть только у слоя 0, остальные слои
берут его bias.

## Формула

$$s_{h,ij} = q_i \cdot k_j + B[\text{bucket}(j - i), h],\qquad \text{bucket}(n) = n \text{ при } n < e,\ \text{иначе } \min\big(e + \lfloor \tfrac{\ln(n/e)}{\ln(d_{\max}/e)}(N' - e)\rfloor, N' - 1\big)$$

## Формы тензоров

```
j − i [T,S] → bucket [T,S] → Embedding(N, H) → [T,S,H] → position_bias [1,H,T,S] → + q·kᵀ
```

## Что поменялось относительно B02

Позиция — не вектор на входе, а скаляр в scores; зависит от j − i, а не от абсолютного номера; обучается; дальние
расстояния сливаются в общий бакет, поэтому длина обучения не ограничивает длину входа таблицей позиций.
