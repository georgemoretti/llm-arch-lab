## TL;DR

Attention — взвешенное среднее значений $v$ по позициям, где веса — softmax от сходства запроса текущей
позиции с ключами всех позиций. Деление на $\sqrt{D}$ держит дисперсию оценок около 1, иначе softmax
становится one-hot. Causal-маска ($-\infty$ над диагональю, до softmax) запрещает смотреть в будущее.
Веса не зависят от длины контекста: одна голова работает на любой длине до `block_size`.

## Формула

$$\operatorname{softmax}\!\big(QK^{\top}/\sqrt{D} + M\big)V,\qquad M_{ij} = -\infty \text{ при } j > i$$

## Формы тензоров

```
x [B,T,C] → q, k, v [B,T,D] → q@kᵀ/√D [B,T,T] → mask −inf → softmax(dim −1) → @v → out [B,T,D]
```

## Что поменялось относительно A15

Позиции начали обмениваться информацией: каждая собирает взвешенную сумму значений всех прошлых позиций.
Вместо окна фиксированной длины — веса, которые выбираются по содержимому.
