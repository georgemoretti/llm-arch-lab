## Подсказка 1

Подставь в код блока «подслой вернул ноль»: `self_attn(...) = 0`, `mlp(...) = 0`. Что тогда
вернёт `forward`? По формуле должно получиться $y = x + 0 + 0 = x$.

## Подсказка 2

В Pre-Norm норма стоит на **входе подслоя**, но не на остаточном пути. Посмотри, к чему
прибавляется выход attention: к исходному `x` или к чему-то другому?

## Подсказка 3

`h = norm(x); x = h + f(h)` — остаток берётся от нормированного входа, и остаточный поток
нормируется в каждом блоке. Правильно: `x = x + f(norm(x))` для обоих подслоёв.
