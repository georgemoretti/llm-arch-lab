## Подсказка 1

`zip(seq, seq[1:])` перебирает соседние пары одной последовательности. Счётчик — обычный словарь:
`counts[pair] = counts.get(pair, 0) + 1`. Внешний цикл по последовательностям, внутренний по парам: тогда
пары через границу не появятся сами собой.

## Подсказка 2

В `merge_pair` нужен цикл `while` с ручным индексом `i`: при совпадении `seq[i], seq[i + 1]` с парой
добавь `new_id` и сделай `i += 2`, иначе добавь `seq[i]` и `i += 1`. Не забудь условие `i + 1 < len(seq)`
перед проверкой второго элемента.

## Подсказка 3

Самая частая пара с правилом «при равенстве меньшая»:
`best = min(counts, key=lambda p: (-counts[p], p))`. Минус перед частотой превращает минимум в максимум
по частоте, а второй элемент кортежа разбивает ничьи. После выбора:
`merges[best] = new_id`, `seqs = [merge_pair(s, best, new_id) for s in seqs]`. В `build_vocab` обходи
`merges.items()` — словарь Python хранит порядок вставки, а это и есть порядок обучения.
