# Итоговый квиз блока A: от производной до своего GPT

## Зачем это нужно

Блок A пройден: от скаляра с градиентом до GPT, которая учится на твоём ноутбуке и пишет слова. Итоговый
квиз собирает 22 ключевых вопроса из всех четырёх модулей, по 4–6 на модуль. Если на все отвечаешь
уверенно, фундамент для блока C готов.

## Что ты построил → где это в блоке C

Блок C начинается с готовой GPT-2 (`llmlab/core/gpt2.py`), и каждая его задача — изменение одной детали.
Почти каждая деталь у тебя уже есть.

| что ты построил | задачи A | где это в блоке C |
|---|---|---|
| autograd, chain rule, проверка градиентов | A01–A03 | autograd PyTorch во всех задачах; свои backward проверяются так же |
| softmax + cross-entropy, logsumexp | A04, A04d | лосс языковой модели везде; сэмплирование в C25a |
| LayerNorm и её градиент | A05, A17 | C01 RMSNorm вместо LayerNorm, C09 QK-Norm |
| инициализация $\mathcal N(0, 0.02^2)$, уменьшенные `c_proj` | A06, A18 | `core/gpt2.py`, конфиги моделей в C24 |
| AdamW, warmup + cosine, clipping | A07, A08 | так обучены модели, чьи веса загружаются в C25 (в блоке C модели не обучаются); рецепт Llama 2 — в README A07, A08 |
| eval-режим, `no_grad`, перплексия | A09, A10 | генерация и сверка логитов с transformers в C25 |
| byte-level BPE, регулярка GPT-2 | A11–A14 | токенизатор Qwen3 в C25 — тот же byte-level BPE, через библиотеку tokenizers |
| эмбеддинги и обучаемые позиции | A15 | C03 RoPE и C10 NoPE заменяют `wpe` |
| weight tying | A15 | связанные эмбеддинги в C06 и у Qwen3-0.6B (C25) |
| одноголовое causal attention | A16 | C00 многоголовое; C04 GQA; C05 KV-cache; C07 SWA; C16 MLA; C20 линейное |
| pre-LN блок, GELU-MLP | A17 | C02 SwiGLU вместо GELU-MLP; C06 блок Llama; C08 размещение норм; C13 MoE вместо MLP |
| мини-GPT и генерация | A18 | C06 модель Llama, C25a сэмплирование, C25 Qwen3 на реальных весах |

Следующая задача — **C00**: твоя голова из A16 становится многоголовым attention GPT-2.

## Как проходить

1. Открой вкладку **«Вопросы»**.
2. В вопросах с вариантами выбери ответ: сразу будет видно, верен ли он, и объяснение.
3. На открытые вопросы сначала ответь сам (2–4 предложения), затем открой эталон и честно оцени ответ.
4. Если ответил неуверенно, вернись к задаче из таблицы. Её конспект лежит во вкладке «Конспекты».

Оценки попадают в интервальное повторение (SM-2) во вкладке **Interview**.
