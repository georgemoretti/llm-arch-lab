## TL;DR

Окно SWA из $W$ позиций включает сам токен: разрешены расстояния $0..W-1$, условие строгое —
$p - j < W$ (или $j > p - W$). Нестрогое $j \ge p - W$ даёт окно $W + 1$: модель работает, но не
совпадает с эталоном и с кольцевым кешем, где лишнего токена уже нет. Проверка — `window=1`
должен давать диагональную маску.

## Формула

$$M_{p,j} = 0 \iff 0 \le p - j < W \quad(\text{а не } \le W)$$

## Формы тензоров

```
mask = (k_pos <= q_pos) & (q_pos − k_pos < W)     [T, S]; в каждой строке min(p + 1, W) единиц
```

## Что поменялось относительно C07

Ничего в архитектуре: это C07 с ошибкой на единицу в границе окна. Урок — проверять маску на
вырожденных случаях (`W = 1`, `W ≥ T`) и считать единицы в строках.
