## TL;DR

Градиент проверяют центральными разностями $(f(x+h) - f(x-h)) / 2h$ в float64 при $h \approx 10^{-5}$.
У этой формулы ошибка $\sim h^2$ против $\sim h$ у односторонней. Меньшее $h$ хуже, потому что
растёт ошибка округления. Сравнивают **относительной** ошибкой с $\varepsilon$ в знаменателе. Это
медленно (2 вызова на параметр), поэтому проверку делают только при отладке и на маленьких размерах.

## Формула

$$\frac{\partial f}{\partial x_i} \approx \frac{f(x + h e_i) - f(x - h e_i)}{2h},\qquad \operatorname{rel}(a,b) = \max_i \frac{|a_i - b_i|}{\max(|a_i|, |b_i|, \varepsilon)}$$

## Формы тензоров

```
x [любая] → для каждого i: f(x ± h·e_i) → grad [та же форма] → rel_error(grad, backward) → float
```

## Что поменялось относительно A01

Autograd считает производную из локальных производных. Здесь производная считается только по
значениям функции, без знания формул: медленно и приближённо, зато независимо. Поэтому численный
градиент служит эталоном при проверке любого backward.
