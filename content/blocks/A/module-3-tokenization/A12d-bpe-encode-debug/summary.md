## TL;DR

Encode по частоте пар в кодируемом тексте вместо ранга обучения выглядит рабочим: decode восстанавливает
текст, сжатие почти такое же. Но разбиение зависит от контекста и не совпадает с обучением. Ловит это
инвариант «encode обучающего текста = последовательность из обучения».

## Формула

$$\text{ошибка: } \arg\max_{(a,b)\in\text{merges}} \operatorname{count}(a,b) \quad\text{вместо}\quad \arg\min_{(a,b)} r(a,b)$$

## Формы тензоров

```
text → bytes [n] → слияния → ids [n′] — формы не меняются, меняются сами id
```

## Что поменялось относительно A12

Ничего в механизме: найден выбор пары по частоте вместо ранга.
