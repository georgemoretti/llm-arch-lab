# Итоговый квиз блока B: от Transformer к ModernBERT и эмбеддингам

## Зачем это нужно

Блок B прошёл вторую ветку эволюции трансформеров: энкодер-декодер 2017 года, BERT и его наследники, T5, ModernBERT и
эмбеддинги для поиска. Квиз собирает по 3–6 ключевых вопросов из каждого модуля, два вопроса с собеседований и два
вопроса на связь с блоком C. Если на какой-то вопрос ответить не получается, загляни в таблицу ниже и вернись к задаче.

## Энкодеры → декодеры: что общего с блоком C

Энкодеры и декодеры пережили одни и те же переходы, часто с разницей в несколько лет. Поэтому ModernBERT 2024 года
похож на Llama больше, чем на BERT 2018-го.

| компонент | энкодеры (блок B) | декодеры (блок C) | вывод |
|---|---|---|---|
| маска attention | двунаправленная + PAD-ключи (`B01`); окно ±W/2 (`B16`) | causal (`C00`); окно назад (`C07`) | механизм один, меняется только маска |
| позиции | синусоиды (`B02`) → таблица BERT (`B10`) → относительный bias T5 (`B13`) → RoPE (`B16`) | таблица GPT-2 → RoPE (`C03`) → RoPE + NoPE-слои (`C10`) | обе ветки пришли к относительным позициям в scores |
| норма | Post-LN (`B03`, `B10`) → Pre-LN RMSNorm T5 (`B14`) → Pre-LN без bias (`B16`) | Pre-LN RMSNorm (`C01`, `C08`), QK-Norm (`C09`) | Pre-LN + финальная норма победили везде |
| FFN | ReLU (`B03`) → GELU (`B10`) → GeGLU (T5 v1.1, `B16`) | GELU GPT-2 → SwiGLU (`C02`), GeGLU Gemma | GLU-FFN с гейтом — стандарт обеих веток |
| bias в линейных слоях | есть у BERT; нет у T5 и ModernBERT (`B14`, `B16`) | нет у Llama и потомков | bias не нужен, Pre-LN и так стабилизирует |
| дальние связи дёшево | глобальный слой через два локальных (`B16`) | sliding : full = 5 : 1 у Gemma 3 (`C07`), гибриды (`C22`) | дорогой глобальный слой — не в каждом слое |
| цель обучения | MLM 15 % (`B09`), span corruption (`B15`), у ModernBERT MLM 30 % | следующий токен (`A18`, `C06`), MTP (`C17`) | энкодер видит всё и учится восстанавливать, декодер — продолжать |
| эффективность | unpadding и `cu_seqlens` (`B17`): один проход, кеш не нужен | KV-cache (`C05`), GQA / MLA (`C04`, `C16`), packing с `cu_seqlens` при SFT | `cu_seqlens` из B17 работает и для декодеров |
| сжатие модели | дистилляция DistilBERT (`B12`) | дистилляция маленьких моделей (например, Gemma 2 2B и 9B) | тот же лосс $T^2\cdot\mathrm{KL}$ |
| выход | вектор текста, метка, span (`B11`, `B18`) | следующий токен, текст | энкодер — для понимания и поиска, декодер — для генерации |

## Как проходить

1. Открой вкладку **«Вопросы»**.
2. В вопросах с вариантами выбери ответ: сразу будет видно, верен ли он, и объяснение.
3. На открытые вопросы сначала ответь сам (2–4 предложения), затем открой эталон и честно оцени ответ.
4. Если ответил неуверенно, вернись к задаче из таблицы. Её конспект лежит во вкладке «Конспекты».

Оценки попадают в интервальное повторение (SM-2) во вкладке **Interview**. Блок B на этом закончен. Блок C (декодеры)
можно проходить в любом порядке с ним: если ты начал с B, многое в C покажется знакомым.
