## TL;DR

При обратной сборке MoE вклады $k$ экспертов токена нужно **складывать** (`index_add_`), а не
записывать (`out[tok] = y`, `index_copy_`): запись оставляет вклад только последнего эксперта. При
top-1 ошибка не видна — у токена один эксперт; поэтому MoE тестируют на $k \ge 2$ и сравнивают с
наивной реализацией.

## Формула

$$y_n = \sum_{j} w_{n,j}\,\text{FFN}_{e_{n,j}}(x_n)\quad(\text{а не } w_{n,j^*}\,\text{FFN}_{e_{n,j^*}}(x_n))$$

## Формы тензоров

```
out [N,C];  для эксперта e: out.index_add_(0, tok_e, y_e)  — сложение по индексам
```

## Что поменялось относительно C13

Ничего в архитектуре: это C13, где вклады экспертов перезаписывают друг друга. Урок — тестировать
MoE на top-k ≥ 2 и против наивной реализации.
