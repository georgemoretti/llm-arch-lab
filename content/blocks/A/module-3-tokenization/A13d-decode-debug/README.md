# Отладка: после decode в тексте появляются «�»

## Зачем это нужно

Ошибки в decode коварны: encode в порядке, модель обучается на правильных id, лосс падает. Ломается
только то, что видит человек, — сгенерированный текст. На английском ошибки может не быть видно
неделями: там почти каждый токен — целые символы ASCII. А на русском тексте, эмодзи и иероглифах она
проявляется сразу.

## Что поменялось относительно A13

Ничего: это те же функции, что в A13. Их написал кто-то другой, и в коде **одна** ошибка.

## Формула

Decode должен быть обратным к encode для любой строки:

$$
\operatorname{decode}(\operatorname{encode}(s)) = s.
$$

## Формы тензоров

```shapes
- text: строка
> encode_with_special
ids [n]
> decode_with_special
- text: должна совпасть с исходной
```

Пре-токенизация, обучение, спецтокены и encode в порядке.

## Симптом

- куски, отображение байтов, обучение и encode проходят свои тесты;
- `decode_with_special([72, 105, eot, 33])` правильно возвращает `Hi<|endoftext|>!`;
