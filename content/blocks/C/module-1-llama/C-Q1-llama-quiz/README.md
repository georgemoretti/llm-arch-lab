# Квиз модуля: GPT-2 → Llama

## Зачем это нужно

Реализовать механизм и объяснить его на собеседовании — разные навыки. Квиз собирает вопросы по
всему модулю: RMSNorm, SwiGLU, RoPE, GQA, KV-cache и сборка блока. Часть вопросов — с выбором
ответа, часть — открытые: на них отвечай своими словами, а потом сравнивай с эталоном.

## Что поменялось относительно GPT-2 — в одной таблице

Проверь, что можешь объяснить каждую строку, не подглядывая в задачи.

| | GPT-2 | Llama 3 | задача |
|---|---|---|---|
| нормализация | LayerNorm | RMSNorm | C01 |
| FFN | GELU-MLP, 4d | SwiGLU, ≈ 8/3·d | C02 |
| позиции | обучаемые абсолютные `wpe` | RoPE на q и k в каждом слое | C03 |
| attention | MHA | GQA (32 / 8 голов) | C04 |
| инференс | — | KV-cache: позиции и маска со сдвигом | C05 |
| bias, выходной слой | bias везде, `lm_head` связан с `wte` | без bias, `lm_head` отдельный | C06 |

## Как проходить

1. Открой вкладку **«Вопросы»**.
2. Для вопросов с вариантами — выбери ответ, сразу увидишь, верно ли, и объяснение.
3. Для открытых — сначала ответь сам (лучше письменно, 2–4 предложения), затем открой эталон и
   честно оцени: всё ли главное ты назвал.
4. Ответил неуверенно — вернись к задаче из таблицы выше, её конспект во вкладке «Конспекты».

Сейчас прогресс по квизу не сохраняется. Флеш-карточки, интервальное повторение (SM-2) и вопросы
с твоих собеседований появятся в Фазе 7 (вкладка Interview).
