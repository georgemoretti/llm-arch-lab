## TL;DR

Дообучение BERT = предобученный энкодер + маленькая голова, обучается вся модель. Классификация — Linear над
pooled `[CLS]`. Разметка токенов — Linear над каждым токеном; метка слова на первом подтокене, `−100` на остальных.
Extractive QA — две оценки на токен (начало, конец), лосс — среднее двух cross-entropy, ответ — argmax суммы
$s_i + e_j$ по парам $i \le j < i + L$ внутри абзаца (не два независимых argmax).

## Формула

$$\mathcal L_{QA} = \tfrac12(\operatorname{CE}(s, i^*) + \operatorname{CE}(e, j^*)),\quad (\hat\imath,\hat\jmath) = \arg\max_{i \le j < i+L}(s_i + e_j)$$

## Формы тензоров

```
seq [B,T,H] → pooled [B,H] → [B,n];  seq → [B,T,n_tags];  seq → s, e [B,T] → пары [B,T,T] → span
```

## Что поменялось относительно B10

Вместо MLM-головы — головы задач; модель дообучается на размеченных данных. Появились выравнивание меток по
подтокенам и постобработка ответа.
