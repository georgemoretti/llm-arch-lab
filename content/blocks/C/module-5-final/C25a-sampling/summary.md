## TL;DR

Сэмплирование выбирает следующий токен случайно из $\operatorname{softmax}(z / T)$ на отсечённом наборе: $T$
обостряет ($T < 1$) или сглаживает ($T > 1$) распределение; top-k оставляет $k$ лучших; top-p — наименьший
префикс отсортированных вероятностей с суммой $\ge p$ (размер подстраивается под уверенность модели). Отсекают
логиты ($-\infty$), перенормирует softmax. В top-p условие — масса токенов **выше** текущего $< p$: токен,
пересёкший порог, остаётся, первый остаётся всегда. $T = 0$ или $k = 1$ — снова жадный выбор.

## Формула

$$\text{keep}_i = [\,i \le k\,] \wedge \Big[\sum_{j<i} p_{(j)} < p\Big],\qquad
x_{t+1} \sim \operatorname{softmax}(z / T)\big|_{\text{keep}}$$

## Формы тензоров

```
logits [B, V] → / T → top-k: kth [B, 1], mask → top-p: sort [B, V], before = cumsum − p [B, V], scatter → multinomial → [B, 1] long
```

## Что поменялось относительно C06

Вместо argmax — случайный выбор с `torch.Generator` (воспроизводимо) и тремя ручками: temperature, top-k,
top-p. Жадная генерация остаётся частным случаем ($T = 0$).
