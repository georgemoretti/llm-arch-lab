# Отладка: после упаковки батча эмбеддинги текстов зависят от соседей

## Зачем это нужно

Ошибка в упаковке батча не роняет программу: формы правильные, лосс падает, модель учится. Но тексты в батче начинают
подглядывать друг в друга. При обучении это утечка: пример видит соседний пример. При инференсе эмбеддинг текста
зависит от того, с какими текстами он попал в батч. Такие ошибки находят проверкой «упаковка == батч с паддингом» и
проверкой «правка одного текста не меняет остальные».

## Что поменялось относительно B17

Ничего: это те же семь функций, что в B17. Их написал кто-то другой, и в коде **одна** ошибка.

## Формула

Токен упаковки $n$ принадлежит тексту $b$, если $\text{cu}_b \le n < \text{cu}_{b+1}$, и видит только токены своего
текста:

$$\text{mask}[i, j] = \big[\, b(i) = b(j) \,\big].$$

## Формы тензоров

```shapes
attention_mask [B, T]
> unpad_input
cu_seqlens [B+1]
> varlen_mask
mask [N, N]
q [N, H, D]
> varlen_attention
out [N, H, D]
```

## Симптом

- `unpad_input`, `pack`, `unpack`, позиции и `padding_savings` верны: `cu_seqlens = [0, 3, 5, 11, 15]`;
- на батче из одного текста выход упаковки совпадает с батчем с паддингом;
- на батче из нескольких текстов не совпадает. Если поменять текст 1, меняются выходы текста 0 и **первого** токена
  текста 2, а остальные токены текста 2 — нет.
