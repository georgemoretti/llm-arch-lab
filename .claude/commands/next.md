Ты работаешь над проектом LLM Arch Lab. Твоя задача — выполнить ОДНУ следующую фазу целиком,
автономно, и остановиться для ревью.

## 1. Подготовка (только в первый раз)
- Если git не инициализирован: `git init -b main`, коммит "chore: add project plan".
- Если PLAN.md, PROGRESS.md или PROMPTS.md случайно лежат в корне — перенеси их в docs/.

## 2. Выбор фазы
Прочитай CLAUDE.md, docs/PLAN.md, docs/PROGRESS.md.

Аргумент пользователя: `$ARGUMENTS`
- Если в аргументе есть номер фазы — делай её.
- Если в аргументе есть правки или замечания к прошлой фазе — СНАЧАЛА внеси их, закоммить,
  потом переходи к следующей фазе.
- Если в PROGRESS.md есть незавершённая фаза — продолжай её с «Следующего шага».
- Иначе бери следующую по порядку: 0 → 1 → 2 → 3a → 3b → 4 → 5a → 5b → 6a → 6b → 7 → 8 → 9 → A1 → A2 → A3 → A4.
- **Вопросы с собесов:** если в `data/interview_raw/` есть файлы (кроме README.md), а
  Фаза 7 ещё не сделана, выполни Фазу 7 сразу после Фазы 2. Тогда в квизах контентных фаз
  будут реальные вопросы пользователя.

## 3. Выполнение
Возьми промпт этой фазы из docs/PROMPTS.md (для контентных фаз — общий шаблон, id задач —
из PLAN.md) и выполни его.

Режим работы:
- **Автономно.** Не проси подтвердить план и не жди «ок» посреди фазы. Решения принимай сам,
  а спорные записывай в PROGRESS.md → «Решения».
- Спрашивай пользователя только тогда, когда без ответа продолжить невозможно (например,
  непонятен формат файлов в data/interview_raw/). Остальные вопросы собери в финальный отчёт.
- Веди список задач (TaskCreate/TaskUpdate), чтобы был виден прогресс.
- Коммить после каждой логической части, а не одним коммитом в конце.
- Если контекст подходит к концу, остановись на границе задачи, обнови PROGRESS.md с точным
  следующим шагом, закоммить и скажи пользователю: «Фаза не закончена, запусти /next ещё раз».

## 4. Завершение фазы
1. Прогони `pytest tests/` и `llmlab validate --all` (если они уже существуют), почини падения.
2. Обнови docs/PROGRESS.md: фаза помечена завершённой, что сделано, решения, долги, следующая фаза,
   строка в журнале сессий.
3. Коммит. Если настроен git remote — `git push`.
4. Выдай отчёт для ревью строго в таком виде:

```
## Фаза <N> готова

**Сделано:**
- …(3–7 пунктов)

**Посмотри руками (5–10 минут):**
- `<команда>` → <что открыть и на что смотреть>
- <файл> — <зачем>

**Мои решения, которые стоит проверить:**
- …

**Вопросы к тебе (если есть):**
- …

**Дальше:** Фаза <M> — <название>. Запусти `/next` (или `/next <правки>`).
```

5. Остановись. Следующую фазу не начинай.
