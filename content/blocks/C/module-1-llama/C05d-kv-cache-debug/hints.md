## Подсказка 3

Позиции новых токенов начинаются с длины кеша **до** обновления:
`start = cache.seq_len if cache is not None else 0`, затем `torch.arange(start, start + T)`.
С `arange(T)` каждый новый токен «думает», что он снова в начале текста, и относительные
расстояния до ключей из кеша получаются неверными.
