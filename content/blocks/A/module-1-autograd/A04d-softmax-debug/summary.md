## TL;DR

Наивный softmax `exp(z) / Σ exp(z)` переполняется при логитах больше ~709 во float64 (а во float16 —
уже при ~11): inf / inf = nan. Математически softmax не зависит от сдвига, поэтому из каждой строки
вычитают её максимум. Логарифм вероятности берут через logsumexp, а не `log(p)`, потому что `p` может
округлиться до 0.

## Формула

$$\log\operatorname{softmax}(z)_j = (z_j - m) - \log\sum_k e^{z_k - m},\quad m = \max_k z_k$$

## Формы тензоров

```
logits [N,V] → − max по строке → exp, sum, log → log_probs [N,V] → loss [], dlogits [N,V]
```
