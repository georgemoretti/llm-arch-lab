## TL;DR

Языковая модель предсказывает следующий символ по предыдущим. Текст → словарь → индексы → окна
`X [N−k, k]` и цели `Y [N−k]`. Модель Bengio: эмбеддинги окна склеиваются, проходят через tanh-слой и
дают логиты по словарю. Качество меряют перплексией $e^{\text{CE}}$: у модели с равными логитами она
равна $V$. Даже окно из 4 символов заметно лучше биграммной таблицы, потому что эмбеддинги обобщают.

## Формула

$$\text{logits} = W_o\tanh\big(W_h[E_{c_{t-k}};\dots;E_{c_{t-1}}] + b_h\big) + b_o,\qquad \operatorname{PPL} = \exp(\overline{\text{CE}})$$

## Формы тензоров

```
ids [N] → X [N−k, k], Y [N−k];  X [B,k] → emb [B,k,E] → flatten [B,k·E] → tanh [B,H] → logits [B,V]
```
