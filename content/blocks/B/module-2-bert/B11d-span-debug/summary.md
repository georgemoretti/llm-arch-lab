## TL;DR

Независимые argmax начала и конца — частая ошибка постобработки extractive QA: конец может оказаться раньше
начала, а обрезка по длине даёт не лучший допустимый ответ. Правильно — argmax суммы $s_i + e_j$ по всем допустимым
парам ($i \le j < i + L$, обе позиции в контексте): матрица $[T, T]$, маска, один argmax.

## Формула

$$\arg\max_{i \le j < i+L} (s_i + e_j)\quad\text{вместо}\quad (\arg\max_i s_i,\ \arg\max_j e_j)$$

## Формы тензоров

```
s [B,T] + e [B,T] → пары [B,T,T] → маска (j ≥ i, j − i < L, контекст) → argmax → start [B], end [B]
```

## Что поменялось относительно B11

Ничего в механизме: найдена жадная постобработка. Её поймал перебор всех пар на случайных логитах.
