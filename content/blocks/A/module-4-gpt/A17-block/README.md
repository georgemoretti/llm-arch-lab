# Блок трансформера: attention, MLP, остатки, pre-LN и post-LN

## Зачем это нужно

Одна голова attention из A16 умеет одно: собрать взвешенную сумму прошлых позиций. Чтобы модель
понимала текст, такие операции складывают в стопку, и каждый слой уточняет результат предыдущего.
Стопка из одного attention не работает. Нужны ещё три детали, и вместе они образуют **блок
трансформера** — повторяющуюся единицу GPT, Llama и почти всех LLM.

1. **MLP** (feed-forward). Attention смешивает позиции, но почти линейно. MLP обрабатывает каждую
   позицию отдельно: расширяет вектор в 4 раза, применяет нелинейность GELU и сжимает обратно. Здесь
   модель «думает» над тем, что собрало внимание.
2. **Остаточные связи** (residual). Подслой не заменяет вход, а прибавляет к нему поправку:
   $x \leftarrow x + f(x)$. Вход идёт дальше напрямую, как по обходной дороге. В начале обучения
   глубокая сеть ведёт себя почти как тождество, и градиент доходит до первых слоёв без затухания.
3. **LayerNorm** (A05). Приводит вектор каждой позиции к среднему 0 и дисперсии 1, чтобы масштаб
   сигнала не уплывал от слоя к слою.

Вопрос, где стоит нормализация, оказался важным. В исходном Transformer (2017) она стоит **после**
сложения с остатком (post-LN). В GPT-2 и почти во всех современных моделях — **перед** подслоем (pre-LN),
и сам residual-поток не нормализуется. Pre-LN обучается стабильнее без долгого разогрева LR. Почему так,
разберём подробно в C08.

## Что поменялось относительно A16

| | A16 | A17 |
|---|---|---|
| единица | одна голова attention | блок: attention + MLP |
| нелинейность по позиции | нет | MLP: $C \to 4C \to$ GELU $\to C$ |
| вход в следующий слой | выход attention | $x + $ поправка (residual) |
| масштаб сигнала | не контролируется | LayerNorm до подслоя (pre) или после суммы (post) |

## Формула

Pre-LN (GPT-2):

$$
x' = x + \operatorname{Attn}(\operatorname{LN}_1(x)),\qquad
y = x' + \operatorname{MLP}(\operatorname{LN}_2(x')).
$$

Post-LN (Transformer 2017):

$$
x' = \operatorname{LN}_1(x + \operatorname{Attn}(x)),\qquad
y = \operatorname{LN}_2(x' + \operatorname{MLP}(x')).
$$

MLP: $\operatorname{MLP}(h) = W_2\, \operatorname{GELU}(W_1 h + b_1) + b_2$, $W_1 \in \mathbb{R}^{4C \times C}$. GPT-2
считает GELU через tanh-аппроксимацию:
$\operatorname{GELU}(z) \approx \tfrac{z}{2}\big(1 + \tanh\big(\sqrt{2/\pi}\,(z + 0.044715 z^3)\big)\big)$.

Два свойства, которые проверяют тесты. Если выходы attention и MLP нулевые, pre-LN-блок — тождество:
$y = x$. У post-LN последняя операция — LayerNorm, поэтому его выход всегда нормализован, даже при нулевых
подслоях.

## Формы тензоров

```shapes
x [B, T, C] — residual-поток
> ln_1 → attn (A16, одна голова размера C)
a [B, T, C]
> x + a
x′ [B, T, C]
> ln_2 → c_fc: Linear C → 4C
h [B, T, 4C]
> GELU (tanh) → c_proj: Linear 4C → C
m [B, T, C]
> x′ + m
y [B, T, C] — та же форма: блоки ставятся в стопку
axis C = n_embd
```

## Критерии готовности

- MLP совпадает с эталоном: GELU через tanh, не точный GELU и не ReLU;
- pre-LN и post-LN совпадают с эталоном при неединичных весах LayerNorm (ln_1 и ln_2 не перепутаны,
  остаток идёт от x, а не от нормализованного входа, MLP видит x с добавкой attention);
- при нулевых подслоях pre-LN возвращает вход без изменений, а post-LN — `ln_2(ln_1(x))`;
- выход post-LN нормализован по каждой позиции, pre-LN сохраняет масштаб residual-потока;
- блок не пропускает будущее; в стопке из 8 pre-LN-блоков градиент доходит до входа.
