# Квиз модуля: ModernBERT и эмбеддинги текста

## Зачем это нужно

«Чем bi-encoder отличается от cross-encoder», «зачем температура в контрастивном лоссе», «как устроен поиск в RAG и
зачем рядом BM25» — частые вопросы на собеседованиях про поиск, RAG и NLP в проде. В квиз входят вопросы модуля,
шесть вопросов с твоих собеседований про поиск и эмбеддинги для RAG (`iv-retrieval-*`) и четыре про статические
эмбеддинги слов (`iv-embeddings-*`: Word2Vec, GloVe). Последние полезно сравнить с контекстными эмбеддингами из B18.

## Что ты построил в модуле — в одной таблице

| идея | где | что запомнить |
|---|---|---|
| слой ModernBERT | B16 | RoPE (θ 160 000 / 10 000), GeGLU, без bias, Pre-LN + `final_norm`, глобальный слой через два локальных, окно ±64 |
| маска окна | B16 | `|i − j| ≤ W/2`, симметричная; закрытые ключи — `finfo.min`, иначе nan у PAD-запроса |
| unpadding | B17, B17d | `[N, C]` без PAD, `cu_seqlens = [0, L₀, …, N]`, блочная маска, позиции с нуля у каждого текста; граница — `≥` |
| pooling | B18, B18d | mean по маске (PAD ненулевые!) или `[CLS]` — какой учили; затем L2; косинусы — $\hat A\hat B^\top$ |
| bi- / cross-encoder | B18 | bi: документы заранее, поиск — умножение; cross: пара целиком, точнее, но прогон на пару → reranker |
| InfoNCE | B19 | CE по строкам $\hat Q\hat D^\top/\tau$, in-batch негативы, τ 0.01–0.05, hard negatives; recall@k |
| мини-поиск | B20 | ICT без разметки; TF-IDF — сильный соперник; гибрид лучше обоих; анизотропия 0.18 → 0.03 |

## Как проходить

1. Открой вкладку **«Вопросы»**.
2. В вопросах с вариантами выбери ответ: сразу будет видно, верен ли он, и объяснение.
3. На открытые вопросы сначала ответь сам (2–4 предложения), затем открой эталон и честно оцени ответ.
4. Если ответил неуверенно, вернись к задаче из таблицы. Её конспект лежит во вкладке «Конспекты».

Оценки попадают в интервальное повторение (SM-2) во вкладке **Interview**. Дальше — итоговый квиз блока B.
