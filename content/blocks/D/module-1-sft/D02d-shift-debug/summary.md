## TL;DR

Метки сдвинули не в ту сторону: `targets[t] = ids[t − 1]` вместо `ids[t + 1]`. Позиция «предсказывает» токен, который
уже видела, и задача превращается в копирование: лосс за десятки шагов падает почти до нуля, а генерировать модель не
учится. Такие ошибки не видны по кривой лосса. Ловятся распечаткой «позиция → метка» и тестом: первый токен ответа
предсказывает последний токен заголовка.

## Формула

$$y_t = x_{t+1}\ \text{(не}\ x_{t-1}\text{)}: \quad \texttt{targets[:-1] = where(mask[1:], ids[1:], -100)}$$

## Формы тензоров

```
ids [T], mask [T] → targets [T]
```
