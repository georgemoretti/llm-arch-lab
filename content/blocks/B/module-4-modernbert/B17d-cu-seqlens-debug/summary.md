## TL;DR

Номер текста считался строгим сравнением `pos > cu_seqlens[1:]` вместо `>=`. Первый токен каждого текста приписывался
предыдущему тексту, и соседи видели друг друга. Формы, `cu_seqlens` и позиции при этом верные, а на батче из одного
текста всё работает. Ловится сравнением «упаковка == батч с паддингом» и проверкой «правка одного текста не меняет
остальные».

## Формула

$$b(n) = \#\{b : \text{cu}_{b+1} \le n\}\quad (\text{нестрогое сравнение: } \text{cu}_{b+1} \text{ — граница «после последнего»})$$

## Формы тензоров

```
cu [B+1] → seq_id [N] → mask [N,N] = seq_id[:,None] == seq_id[None,:]
```
