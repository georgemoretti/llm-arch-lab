## TL;DR

RMSNorm — LayerNorm без центрирования: вектор токена делится на свой RMS (корень из среднего
квадрата по C) и умножается на обучаемый γ. Нет β, одна редукция вместо двух. Масштаб входа
сокращается полностью, сдвиг — нет. В Llama считается в float32, eps = 1e-5 стоит под корнем.

## Формула

$$\operatorname{RMSNorm}(x)_i = \frac{x_i}{\sqrt{\tfrac{1}{C}\sum_j x_j^2 + \varepsilon}}\,\gamma_i$$

## Формы тензоров

```
x [B,T,C] → float() → pow(2).mean(-1, keepdim) → [B,T,1] → +eps, rsqrt
→ x·inv_rms [B,T,C] → .to(dtype) → ·weight [C] → [B,T,C]
```

## Что поменялось относительно GPT-2

LayerNorm (вычитание среднего, деление на std, γ и β) заменён на RMSNorm (только деление на RMS
и γ). Место нормализаций то же: Pre-Norm перед attention и FFN плюс финальная норма перед
выходным слоем.
