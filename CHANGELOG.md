# Changelog

## Unreleased

Новый необязательный блок B «Энкодеры: от Transformer к BERT и эмбеддингам» (план — четыре модуля, `docs/PLAN.md`).

Блок B, модуль 1 «Transformer: энкодер и декодер»:
- **B01** padding-маска по ключам и двунаправленное multi-head attention (`T ≠ S`, == `nn.MultiheadAttention`);
  **B01d** — головы режутся `view(B, H, L, D)`: с одной головой верно, с четырьмя PAD протекает;
- **B02** синусоидальные позиции, сдвиг как поворот (`PE[p + k] = M_k PE[p]`), эмбеддинги × √d_model;
- **B03** энкодер: слой Post-LN / Pre-LN (== `nn.TransformerEncoderLayer`), стопка с одной padding-маской;
- **B04** декодер и cross-attention (== `nn.TransformerDecoderLayer`); **B04d** — causal-маска в cross-attention;
- **B05** seq2seq целиком: shift right, label smoothing (== `F.cross_entropy(label_smoothing=…)`), общая матрица
  эмбеддингов, greedy decode с одним проходом энкодера; **B05d** — shift right через `torch.roll`;
- **B06** проект: число цифрами → число словами по-русски (0 … 999 999), 2000 примеров → 99.4 % exact match на
  отложенных, ошибки только на коротких числах (сдвиг распределения);
- **B-P1** статьи: Sutskever et al. 2014, Bahdanau et al. 2014, Transformer (энкодер-декодер, регуляризация);
  **B-Q1** квиз модуля; 24 новых вопроса;
- визуализации: маски энкодер-декодера (с ошибкой «маска по запросам»), синусоидальные позиции, карта
  cross-attention обученной модели;
- `llmlab/core/encdec.py` — эталоны B01–B05 для следующих задач и модулей.

Блок B, модуль 2 «BERT»:
- **B07** WordPiece: очистка, uncased-нормализация (NFD — «й» → «и»), пунктуация, жадный longest-match-first с `##`
  (== `tokenizers`; с `--weights` — словарь bert-base-uncased);
- **B08** вход BERT: `[CLS] A [SEP] B [SEP]`, обрезка `longest_first` (== быстрые токенизаторы HF), батч с маской,
  `BertEmbeddings` (== `transformers`);
- **B09** MLM-маскирование: 15 %, 80 / 10 / 10, whole word masking; **B09d** — labels считаются до исключения спецтокенов;
- **B10** модель BERT: Post-LN + GELU, pooler, MLM-голова; state_dict `transformers.BertForMaskedLM` грузится без
  переименований; с `--weights` настоящий bert-base-uncased отвечает «paris»;
- **B11** головы: классификация (== `BertForSequenceClassification`), выравнивание меток NER, QA-лосс, лучший span;
  **B11d** — начало и конец ответа выбраны независимыми argmax;
- **B-P2** статьи BERT и RoBERTa; **B-Q2** квиз модуля; 20 новых вопросов; визуализации WordPiece по шагам и
  MLM-маскирования; `llmlab/core/bert.py`.

Блок B, модуль 3 «DistilBERT и T5»:
- **B12** дистилляция: мягкие метки с температурой, T²·KL (градиент T·(q − p)/N), смесь с hard loss, cosine-loss
  скрытых состояний, ученик DistilBERT из слоёв учителя через один;
- **B13** относительный позиционный bias T5: бакеты (точные + логарифмические), двунаправленный и causal режим
  (== `T5Attention._relative_position_bucket` / `compute_bias`); **B13d** — сдвиг «запрос минус ключ»;
- **B14** слой T5: RMSNorm, Pre-LN, attention без 1/√d, общий bias слоя 0; state_dict `transformers.T5Model`
  грузится без переименований; с `--weights` настоящий t5-small заполняет sentinel-пропуски;
- **B15** span corruption: маска шума T5 (15 %, спаны по 3), sentinel-токены во входе и в цели, пример из статьи;
  **B15d** — сдвиг маски дополнен единицей, sentinel-ы цели съезжают на кусок;
- **B-P3** статьи Hinton et al. 2015, DistilBERT, T5; **B-Q3** квиз модуля; 22 новых вопроса; визуализации
  «температура дистилляции» и «бакеты T5»; `llmlab/core/t5.py`.

## v0.2.0 — 2026-10-18

Новый необязательный блок A «Фундамент: от производной до своего GPT» — 35 задач в четырёх модулях перед блоком C.
Прогресс и конспекты v0.1.x сохраняются: id задач блока C не менялись, навигация получила букву блока («C1.4»).

Блок A «Фундамент» (необязательный), модуль 1 «Autograd»:
- **A01** `Value` — скалярный autograd: граф, локальные производные, обратный проход без рекурсии; **A01d** — градиент
  перезаписывается вместо накопления;
- **A02** проверка градиентов центральными разностями и относительной ошибкой;
- **A03** MLP на `Value`: нейрон, слой, MSE, SGD, цикл обучения (XOR, два кольца);
- **A04** backprop руками на тензорах: Linear, ReLU, softmax + cross-entropy с logsumexp; **A04d** — nan на больших логитах;
- **A05** backward LayerNorm руками;
- **A-P1** статьи: backprop (Rumelhart et al., 1986) и обзор автодифференцирования; **A-Q1** квиз модуля; 21 новый вопрос;
- визуализации: граф autograd по шагам, ошибка численной производной от h, MLP учится в браузере, softmax-CE и
  переполнение, из чего складывается градиент LayerNorm.

Блок A, модуль 2 «Обучение нейросети»:
- **A06** инициализация Xavier / Kaiming и эксперимент «std активаций по глубине»;
- **A07** SGD с momentum, Adam, AdamW руками (совпадают с `torch.optim`); **A07d** — L2 вместо decoupled decay;
- **A08** warmup + cosine и gradient clipping по глобальной норме;
- **A09** тренировочный цикл: батчи, порядок шага, валидация в eval, переобучение на одном батче; **A09d** — забыт `zero_grad`;
- **A10** языковая модель на символах (Bengio 2003) на собственном корпусе `content/data/corpus-ru.txt`;
- **A-P2** (Adam, AdamW), **A-P2b** (Glorot, He, Bengio 2003), **A-Q2** квиз; 23 новых вопроса, 4 вопроса с собеседований
  привязаны к задачам;
- визуализации: активации по глубине, траектории SGD / momentum / Adam, расписания LR, биграммная таблица.

Блок A, модуль 3 «Токенизация»:
- **A11** обучение byte-level BPE: подсчёт пар, слияние, merges с рангами, словарь «id → байты»;
- **A12** encode по рангам и decode через байты; **A12d** — слияния по частоте в тексте вместо ранга;
- **A13** пре-токенизация регуляркой GPT-2, спецтокены, `bytes_to_unicode`; **A13d** — decode по одному токену;
- **A14** свой токенизатор на `vocab.json` / `merges.txt` GPT-2: без сети — игрушечные файлы, с `--weights` — сверка
  с библиотекой `tokenizers` токен в токен;
- **A-P3** статьи: BPE для перевода (Sennrich et al., 2016) и раздел 2.2 GPT-2; **A-Q3** квиз; 22 новых вопроса, 3 вопроса
  с собеседований привязаны к задачам;
- визуализация V-bpe: BPE обучается в браузере, подсветка токенов, таблица слияний, длина текста с регуляркой и без;
- `llmlab/core/bpe.py` — эталоны A11–A13; новая зависимость `regex` (классы Unicode `\p{L}`, `\p{N}`).

Блок A, модуль 4 «Свой GPT»:
- **A15** эмбеддинги токенов и обучаемых позиций, weight tying, стартовый loss ≈ ln V;
- **A16** одноголовое scaled dot-product attention с causal-маской; **A16d** — маска после softmax: нули над диагональю
  на месте, а будущее протекает через знаменатель;
- **A17** блок трансформера: MLP с GELU (tanh), остаточные связи, pre-LN и post-LN;
- **A18** проект: мини-GPT на символах корпуса — forward, батчи, обучение, генерация; полное обучение ~30 с на CPU с
  ранней остановкой по val;
- **A-P4** статья: Attention Is All You Need, раздел 3; **A-Q4** квиз модуля; **A-Q4b** итоговый квиз блока A с
  таблицей «что ты построил → где это в блоке C»; 23 новых вопроса, 9 вопросов с собеседований привязаны к задачам;
- визуализация V-training-curve: предзаписанный прогон мини-GPT (train/val, переобучение, образцы текста по шагам);
- корпус `content/data/corpus-ru.txt` расширен до ~23 тыс. символов (числа в A10–A14 пересчитаны);
- `llmlab/core/minigpt.py` — эталоны A15–A17.

Платформа:
- `recommended_after` в task.yaml — рекомендация «лучше после», которая не блокирует и не влияет на «следующую
  задачу»: C00 рекомендует A16 и A18;
- несколько блоков: номера в навигации с буквой блока — «A1.2», «C1.3» (номер модуля — из id `module-<N>-…`);
- `optional: true` в `block.yaml`: пометка «необязательный» на карте, «следующая задача» не уводит в такой блок тех,
  кто уже идёт по обязательным; id модулей уникальны во всём курсе (проверяет загрузчик);
- ссылки на задачи в тексте (`A04`, `C-P1`) работают для любого блока.

## v0.1.0 — 2026-10-17

Первый выпуск: блок C «Эволюция декодеров» целиком.

**Курс**
- 50 задач в 6 модулях: GPT-2 → Llama (RMSNorm, SwiGLU, RoPE, GQA, KV-cache) → Gemma 3 / OLMo 2 / SmolLM3
  (sliding window, размещение норм, QK-Norm, NoPE) → MoE и DeepSeek (роутер, балансировка, shared expert,
  MLA, MTP) → эффективное внимание и гибриды (DSA, gated attention, линейное внимание, Gated DeltaNet,
  Mamba-2) → финальный проект.
- Типы задач: реализация, отладка (один правдоподобный баг), чтение статей, квизы, проект.
- Финальный проект: модель из YAML через реестр компонентов, загрузка config.json и safetensors с Hugging
  Face, Qwen3-0.6B на своих модулях (логиты совпадают с `transformers` до ~6·10⁻⁵), генерация с
  temperature / top-k / top-p.
- 229 вопросов (курс + собеседования) с интервальным повторением по SM-2.
- Таблица архитектур «модель × компонент» для 9 моделей, открывается по мере решения задач.

**Платформа**
- Веб-интерфейс (React + Monaco + KaTeX, офлайн): карта курса с графом зависимостей, страница задачи,
  интерактивные визуализации, конспекты с поиском и графом связей, Interview.
- Автоконспекты в Markdown, совместимые с Obsidian.
- CLI: `serve`, `list`, `test [--weights]`, `validate`, `notes`, `questions`, `model`, `generate`, `doctor`.
- Проверено на Linux, macOS и Windows (CI: тесты платформы, инварианты всех задач, установка с нуля через uv).
