# WordPiece: токенизатор BERT

## Зачем это нужно

Модуль 2 — BERT: энкодер из B03 без декодера, предобученный восстанавливать закрытые слова. Начинается он,
как любая модель, с токенизатора. У BERT это **WordPiece** — ровесник BPE (A11–A13) с тем же итогом:
словарь подслов, в котором частые слова целые, а редкие собираются из кусков. Но устроен иначе:

- **кодирование** — не слияния по рангам, а жадный поиск по словарю: с начала слова берётся самый длинный
  кусок, который есть в словаре, потом самый длинный из оставшегося — и так до конца;
- **продолжение слова** помечается префиксом `##`: `token ##ization`. Поэтому из токенов всегда видно, где
  начинаются слова. Это пригодится для разметки токенов (B11) и маскирования целых слов (B09);
- **неразбираемое слово** превращается в один `[UNK]` целиком: частичных разборов нет;
- **до** WordPiece текст проходит пре-токенизацию: очистка, нижний регистр и удаление диакритики (у uncased),
  разрез по пробелам и по **каждому** знаку пунктуации.

Здесь ты пишешь кодирование. Обучение словаря WordPiece похоже на BPE, только пара для слияния выбирается не по
частоте, а по выигрышу правдоподобия: $\frac{\text{freq}(ab)}{\text{freq}(a)\,\text{freq}(b)}$. Сам словарь
бери готовый: тесты используют игрушечный, а weights-тест — настоящий словарь `bert-base-uncased`.

## Что поменялось относительно A12

| | BPE GPT-2 (A11–A13) | WordPiece BERT (B07) |
|---|---|---|
| единица | байты | символы Unicode после нормализации |
| регистр | сохраняется | uncased: нижний регистр и без диакритики (`й` → `и`!) |
| кодирование | слияния по рангу, пока есть что сливать | жадный longest-match-first по словарю |
| границы слов | пробел внутри токена (`Ġ`) | `##` у продолжения слова |
| неизвестное | не бывает: любой байт есть в словаре | `[UNK]` на всё слово |
| словарь | 50 257 | 30 522 (`bert-base-uncased`), из них 5 828 — продолжения `##…` |

## Формула

Разбор слова $w$ — последовательность кусков, где каждый следующий кусок — самый длинный префикс остатка из
словаря:

$$
p_1 = \arg\max_{u \,\in\, V,\; w = u\,\cdots} |u|,
\qquad
p_k = \arg\max_{\#\#u \,\in\, V,\; w_{\text{rest}} = u\,\cdots} |u| \quad (k \ge 2).
$$

Жадность не ищет «лучшего» разбиения. Если в словаре есть `una`, `un`, `##aff`, `##ff`, `##able`, то
`unaffable` → `una ##ff ##able`, хотя `un ##aff ##able` осмысленнее. В `bert-base-uncased` выходит
`una ##ffa ##ble`.

## Формы тензоров

```shapes
- текст: «Unaffable, Ёжик!»
> clean_text → lower → strip_accents (NFD, без знаков Mn)
- «unaffable, ежик!»
> split по пробелам, отдельный токен на каждый знак пунктуации
- слова: unaffable | , | ежик | !
> wordpiece для каждого слова
tokens [N] — una ##ff ##able , [UNK] !
```

Тензоров здесь ещё нет: id получатся в B08 из словаря.

## Как BERT видит русский текст

Словарь `bert-base-uncased` собран по английским текстам, кириллических токенов в нём 86. Поэтому
`Привет, мир!` → `п ##р ##и ##в ##е ##т , м ##и ##р !`, а на корпусе курса выходит 19 055 токенов на 4 303
слова (4.4 на слово). К тому же uncased-нормализация стирает кратку: `йогурт` → `и ##о ##г ##у ##р ##т`. Для
русского берут мультиязычные модели (`bert-base-multilingual-cased`) или русские (ruBERT): у них свои словари
и обычно cased-нормализация.

## Задание

В `solution.py` (рабочая копия в `workspace/B07-wordpiece/`):

1. `strip_accents(text)` — NFD и удаление символов категории `Mn`.
2. `basic_tokenize(text, lower=True)` — `clean_text`, нижний регистр и `strip_accents` при `lower`, разрез по
   пробелам и пунктуации (`is_punctuation` готова).
3. `wordpiece(word, vocab, unk, max_chars)` — жадный разбор слова.
4. `tokenize(text, vocab, lower=True)`.

## Критерии готовности

- `café` → `cafe`, `йод` → `иод`, кириллица без диакритики не меняется;
- каждый знак пунктуации — отдельное слово, невидимые и управляющие символы убраны, `lower=False` сохраняет текст;
- разбор жадный по самому длинному куску; продолжения только с `##`; неразбираемое слово → один `[UNK]`;
  слово длиннее `max_chars` → `[UNK]`;
- на корпусе курса — те же токены, что у библиотеки `tokenizers`; с `--weights` — то же, что официальный
  токенизатор `bert-base-uncased`.

Запуск: `llmlab test B07-wordpiece` (с проверкой на настоящем словаре: `llmlab test B07-wordpiece --weights`).
