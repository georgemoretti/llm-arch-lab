## Подсказка 1

Раз по одному токену всё верно, а в куске верен только последний выход — какое состояние видит запрос
$q_t$ в куске? Должно быть $S_t$ — состояние сразу после записи токена $t$.

## Подсказка 2

Посмотри, где считается выход: внутри цикла по $t$ или после него. После цикла у тебя есть только $S_T$ —
состояние, в которое уже записаны все токены куска, включая будущие для $q_t$.

## Подсказка 3

Выход читается в цикле, сразу после записи: `outs.append((S * q[:, :, t, :, None]).sum(dim=-2))`, а в конце
`torch.stack(outs, dim=2)`. Свернуть чтение в одно умножение нельзя — у каждого $t$ своё $S_t$ (это и делает
чанковая форма, но с маской внутри куска).
