## TL;DR

QK-Norm должна стоять до RoPE. При единичных весах нормы (инициализация) порядок не важен: RoPE
сохраняет длину, а деление на RMS коммутирует с поворотом. С обученными весами — важен: умножение
на разные веса каналов не коммутирует с поворотом пары каналов. Поэтому ошибка не видна ни на
свежей модели, ни в тестах форм — только при сравнении с эталоном на неединичных весах.

## Формула

$$R\,(w \odot \hat q) \ne w \odot (R\,\hat q)\ \text{ если } w_i \ne w_{i + D/2};\qquad \text{верно: } R\,\operatorname{RMSNorm}_w(q)$$

## Формы тензоров

```
q [B,H,T,D] → q_norm (по D) → apply_rope → scores
```

## Что поменялось относительно C09

Ничего в архитектуре: это C09, где в режиме по голове норма применена после RoPE. Урок — тестировать
загрузку весов на случайных (неединичных) значениях параметров, а не только на инициализации.
