## TL;DR

Четыре места для нормы в блоке: Post-Norm $n(x + f(x))$ (Transformer 2017) держит остаток с RMS = 1,
но градиенты верхних слоёв при инициализации большие при любой глубине — нужен warmup. Pre-Norm
$x + f(n(x))$ (GPT-2, Llama) оставляет «чистый» остаточный путь: блок с нулевыми подслоями —
тождество, градиенты верхних слоёв падают ~ $1/\sqrt{L}$, обучение стабильнее, но остаток растёт.
OLMo 2 — $x + n(f(x))$: норма на выходе подслоя внутри остатка. Gemma 2/3 — sandwich
$x + n_2(f(n_1(x)))$. У последних двух вклад подслоя ограничен (RMS ≈ 1), остаток растёт как $\sqrt{1 + 2L}$.

## Формула

$$\text{Post: } n(x + f(x)),\quad \text{Pre: } x + f(n(x)),\quad \text{OLMo 2: } x + n(f(x)),\quad \text{Sandwich: } x + n_2(f(n_1(x)))$$

## Формы тензоров

```
x [B,T,C] → (норма / подслой / + остаток в нужном порядке) → [B,T,C]; формы во всех вариантах одинаковы
```

## Что поменялось относительно C06

Подслои те же (`LlamaAttention`, `SwiGLUFFN`), меняется порядок «норма → подслой → сложение».
Llama — Pre-Norm; OLMo 2 переносит норму на выход подслоя и убирает входную; Gemma ставит обе.
