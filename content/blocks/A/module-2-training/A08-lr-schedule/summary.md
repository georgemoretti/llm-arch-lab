## TL;DR

lr — функция шага: линейный warmup с $\eta_{\max}(t+1)/W$ (стабилизирует начало, пока моменты Adam не
накоплены), затем cosine до $\eta_{\min}$. Gradient clipping считает **одну** норму по всем градиентам
и масштабирует их все на $\min(1, c/\lVert g\rVert)$: выбросы не ломают веса, направление сохраняется.
Порядок: backward → clip → установить lr → step.

## Формула

$$\eta(t) = \eta_{\min} + \tfrac{1}{2}(\eta_{\max}-\eta_{\min})\big(1+\cos(\pi\tfrac{t-W}{T-W})\big),\qquad g \leftarrow g\min\big(1, \tfrac{c}{\lVert g\rVert+\varepsilon}\big)$$

## Формы тензоров

```
все g_p → одна норма ‖g‖ [] → общий coef → g_p (те же формы)
```
