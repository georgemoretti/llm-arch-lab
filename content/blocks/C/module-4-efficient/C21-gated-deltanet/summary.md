## TL;DR

DeltaNet хранит память «ключ → значение» в матрице $S$ $[d_k, d_v]$ и обновляет её правилом дельты:
$S \mathrel{+}= \beta k (v - S^\top k)^\top$ — шаг градиентного спуска по $\lVert S^\top k - v\rVert^2$, поэтому значение по ключу
перезаписывается, а не накапливается, как в линейном внимании. Gated DeltaNet добавляет гейт забывания
$\alpha = e^{g}$ (как в Mamba-2): гейт стирает память целиком, дельта правит отдельные пары. Ключи L2-нормированы,
$\beta = \sigma(b)$, $g = -e^{A}\operatorname{softplus}(a + \Delta_b)$. В Qwen3-Next это 3 из 4 слоёв; состояние слоя — константа по длине.

## Формула

$$S_t = e^{g_t} S_{t-1}\,(I - \beta_t k_t k_t^\top) + \beta_t k_t v_t^\top,\qquad o_t = S_t^\top q_t / \sqrt{d_k}$$

## Формы тензоров

```
q,k [B,H,T,dk] (L2), v [B,H,T,dv], β,g [B,H,T];  S [B,H,dk,dv]: S←e^g S → v_old=Sᵀk [B,H,dv] → S+=k⊗β(v−v_old) → o=Sᵀq/√dk
```

## Что поменялось относительно C20

Вместо $S \mathrel{+}= \varphi(k)v^\top$ и деления на $\varphi(q)^\top z$ — запись разности $\beta(v - S^\top k)$, L2-нормированные q/k
и гейт забывания $e^{g}$. Память умеет перезаписывать и забывать.
