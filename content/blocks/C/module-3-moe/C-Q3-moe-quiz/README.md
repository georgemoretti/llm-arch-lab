# Квиз модуля: MoE и DeepSeek

## Зачем это нужно

MoE и MLA — самые частые темы вопросов про современные LLM: «сколько у модели активных
параметров и почему», «как работает роутер», «чем MLA лучше GQA». Квиз собирает вопросы по всем
задачам модуля — с вариантами ответа и открытые.

## Что поменялось относительно Llama — в одной таблице

Проверь, что можешь объяснить каждую строку, не подглядывая в задачи.

| | Llama 3 8B | Mixtral 8x7B | DeepSeek-V3 | задача |
|---|---|---|---|---|
| FFN | dense SwiGLU | 8 экспертов, top-2 | 256 узких routed (top-8) + 1 shared | C12, C13, C15 |
| роутер | — | softmax → top-2 → перенормировка | sigmoid + bias → top-8 → норм. ×2.5 | C12 |
| балансировка | — | aux loss (коэф. 0.02) | bias без градиента (+ малый aux loss) | C14 |
| первые слои | — | все MoE | первые 3 — dense | C15 |
| attention | GQA (8 KV-голов) | GQA (8 KV-голов) | MLA: латент 512 + RoPE-ключ 64 | C16, C16b |
| кеш на токен (bf16) | 128 КиБ | 128 КиБ | ≈ 69 КиБ при 61 слое и 128 головах | C16b |
| loss | следующий токен | следующий токен | + MTP (глубина 1, λ = 0.3 → 0.1) | C17 |

Источники чисел — config.json моделей на Hugging Face и отчёт DeepSeek-V3 (ссылки в task.yaml задач).

## Как проходить

1. Открой вкладку **«Вопросы»**.
2. Для вопросов с вариантами — выбери ответ, сразу увидишь, верно ли, и объяснение.
3. Для открытых — сначала ответь сам (2–4 предложения), затем открой эталон и честно оцени.
4. Ответил неуверенно — вернись к задаче из таблицы, её конспект во вкладке «Конспекты».
