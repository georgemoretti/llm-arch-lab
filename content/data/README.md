# Данные курса

- `corpus-ru.txt` — небольшой русский текст (~23 тыс. символов, ~42 КБ) для языковых моделей блока A (A10, модуль 4).
  Написан авторами курса специально для него, распространяется по лицензии репозитория (MIT). Чужих текстов
  здесь нет: при добавлении данных указывайте источник и лицензию.
- `course-search.json` — снимок корпуса проекта B20: абзацы README задач курса и вопросы курса (`source: course`) с
  привязкой к задачам. Тексты написаны авторами курса (MIT). Снимок заморожен, чтобы числа в README B20 не менялись с
  ростом курса; пересобрать: `python content/blocks/B/module-4-modernbert/B20-mini-search/solution.py --rebuild-corpus`.
