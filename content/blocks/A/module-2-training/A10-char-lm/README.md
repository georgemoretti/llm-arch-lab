# Языковая модель на символах: окно → следующий символ

## Зачем это нужно

Языковая модель решает одну задачу: по началу текста предсказывает распределение следующего символа
или токена. GPT, Llama и все модели блока C делают ровно это, только с токенами вместо букв и с
attention вместо фиксированного окна. В этой задаче ты соберёшь первую настоящую языковую модель
целиком: от сырого текста до перплексии на отложенной части и сгенерированных строк.

Модель повторяет идею Bengio et al. (2003). Каждый символ получает обучаемый вектор (**эмбеддинг**),
эмбеддинги последних $k$ символов склеиваются и проходят через скрытый слой. Таблица частот не умеет
обобщать на сочетания, которых не видела. Эмбеддинги умеют: похожие символы получают похожие векторы,
и знания переносятся между контекстами.

Корпус для обучения — `content/data/corpus-ru.txt`, около 23 тысяч символов текста, написанного для
курса.

## Что поменялось относительно A09

| | A09 | A10 |
|---|---|---|
| данные | готовые точки и метки | текст → словарь → индексы → окна |
| вход модели | вектор признаков | индексы символов → `nn.Embedding` |
| выход | 3 класса | V классов — весь словарь |
| метрика | лосс, точность | **перплексия** $= e^{\text{CE}}$ |
| ориентир | — | биграммная модель по частотам |

## Формула

Окно из $k$ символов $c_{t-k}, \dots, c_{t-1}$, матрица эмбеддингов $E \in \mathbb{R}^{V \times d}$:

$$
x = [E_{c_{t-k}};\ \dots;\ E_{c_{t-1}}] \in \mathbb{R}^{k d},\qquad
h = \tanh(W_h x + b_h),\qquad
\text{logits} = W_o h + b_o \in \mathbb{R}^{V}.
$$

Обучение минимизирует cross-entropy со следующим символом $c_t$. **Перплексия** —
экспонента средней cross-entropy:

$$
\operatorname{PPL} = \exp\Big(-\frac{1}{N}\sum_{t} \log p(c_t \mid c_{t-k:t-1})\Big).
$$

Её можно читать как «между сколькими символами модель в среднем выбирает». Модель с одинаковыми
логитами для всех символов имеет перплексию ровно $V$, идеальная — 1.

## Формы тензоров

```shapes
- text: строка корпуса
> build_vocab, encode
ids [N] — индексы символов (long)
> make_dataset: окна длины k
X [N − k, k] — контексты
Y [N − k] — следующий символ
## forward
X [B, k]
> emb: nn.Embedding(V, E)
e [B, k, E]
> flatten(1): склейка окна
x [B, k·E]
> tanh(hidden)
h [B, H]
> out
logits [B, V]
axis k = длина окна (context)
axis E = размер эмбеддинга
axis H = скрытый слой
```

## Задание

В `solution.py` (рабочая копия в `workspace/A10-char-lm/`):

1. `build_vocab(text)` → `(stoi, itos)`, где `itos` — символы по возрастанию; `encode` и `decode`.
2. `make_dataset(ids, context)` → `X [N − k, k]`, `Y [N − k]`.
3. `MLPLM.forward(X)` → логиты `[B, V]` (без softmax). Конструктор готов.
4. `perplexity(model, X, Y)` → `float` в режиме eval; режим модели потом восстанавливается.

`generate` уже написан: после обучения им можно посмотреть, что модель сочиняет.

## Критерии готовности

- словарь из 67 символов, `stoi` и `itos` взаимно обратные;
- `encode` возвращает `long`, `decode(encode(s)) == s`;
- `make_dataset` даёт ровно $N - k$ окон, последнее окно имеет следующий символ;
- логиты совпадают с эталоном при тех же весах, склейка в правильном порядке, без softmax;
- у модели с одинаковыми логитами перплексия ровно 67;
- после 400 шагов обучения перплексия на отложенных 10% текста хотя бы на 10% ниже, чем у
  биграммной модели по частотам.

Запуск: `llmlab test A10-char-lm`.
