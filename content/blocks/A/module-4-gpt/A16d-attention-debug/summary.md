## TL;DR

Маска после softmax — ошибка с двумя симптомами. Строки весов перестают суммироваться в 1. И, что
опаснее, будущее протекает через знаменатель softmax: вес прошлого ключа $e^{s_j} / \sum_{\text{все } k} e^{s_k}$
зависит от оценок будущих ключей. Матрица весов при этом выглядит правильной (нули над диагональю).
Правильно: $-\infty$ в оценки до softmax.

## Формула

$$\text{ошибка: } \frac{e^{s_{tj}}}{\sum_{k=1}^{T} e^{s_{tk}}}\cdot[j \le t] \quad\text{вместо}\quad \frac{e^{s_{tj}}}{\sum_{k \le t} e^{s_{tk}}}$$

## Формы тензоров

```
scores [B,T,T] → masked_fill(−inf) → softmax → weights [B,T,T] (а не softmax → masked_fill(0))
```

## Что поменялось относительно A16

Ничего в механизме: найдена маска, применённая после softmax. Проверка «выход не зависит от будущего»
поймала её, хотя нули над диагональю были на месте.
