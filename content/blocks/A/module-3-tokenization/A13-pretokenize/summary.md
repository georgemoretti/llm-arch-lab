## TL;DR

Перед BPE текст режется регуляркой GPT-2 на куски: сокращения, « слово» с пробелом в начале, числа,
пунктуация, пробелы. Слияния живут только внутри кусков, поэтому словарь не тратится на сочетания соседних
слов, а слово всегда кодируется одинаково. Спецтокены (`<|endoftext|>`) вырезаются до пре-токенизации и
получают один id. Для текстовых файлов словаря каждый байт отображается в печатный символ: `Ġ` = пробел,
`Ċ` = перевод строки. GPT-2: 256 байтов + 50 000 слияний + `<|endoftext|>` (id 50 256) = 50 257 токенов.

## Формула

$$u(b) = \operatorname{chr}(b)\ \text{для 188 видимых байтов},\qquad u(b) = \operatorname{chr}(256 + j)\ \text{для } j\text{-го из остальных 68};\quad u(32) = \text{Ġ}$$

## Формы тензоров

```
text → split_special → [часть | спецтокен] → pretokenize → куски → encode(кусок) → ids;  decode: байты всех id → join → utf-8
```

## Что поменялось относительно A12

BPE применяется к кускам, а не ко всему тексту; появились спецтокены и отображение байтов в печатные
символы, без которого не прочитать файлы словаря GPT-2 (A14).
