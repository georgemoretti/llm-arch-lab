# Changelog

## v0.1.0 — 2026-10-17

Первый выпуск: блок C «Эволюция декодеров» целиком.

**Курс**
- 50 задач в 6 модулях: GPT-2 → Llama (RMSNorm, SwiGLU, RoPE, GQA, KV-cache) → Gemma 3 / OLMo 2 / SmolLM3
  (sliding window, размещение норм, QK-Norm, NoPE) → MoE и DeepSeek (роутер, балансировка, shared expert,
  MLA, MTP) → эффективное внимание и гибриды (DSA, gated attention, линейное внимание, Gated DeltaNet,
  Mamba-2) → финальный проект.
- Типы задач: реализация, отладка (один правдоподобный баг), чтение статей, квизы, проект.
- Финальный проект: модель из YAML через реестр компонентов, загрузка config.json и safetensors с Hugging
  Face, Qwen3-0.6B на своих модулях (логиты совпадают с `transformers` до ~6·10⁻⁵), генерация с
  temperature / top-k / top-p.
- 229 вопросов (курс + собеседования) с интервальным повторением по SM-2.
- Таблица архитектур «модель × компонент» для 9 моделей, открывается по мере решения задач.

**Платформа**
- Веб-интерфейс (React + Monaco + KaTeX, офлайн): карта курса с графом зависимостей, страница задачи,
  интерактивные визуализации, конспекты с поиском и графом связей, Interview.
- Автоконспекты в Markdown, совместимые с Obsidian.
- CLI: `serve`, `list`, `test [--weights]`, `validate`, `notes`, `questions`, `model`, `generate`, `doctor`.
- Проверено на Linux, macOS и Windows (CI: тесты платформы, инварианты всех задач, установка с нуля через uv).
