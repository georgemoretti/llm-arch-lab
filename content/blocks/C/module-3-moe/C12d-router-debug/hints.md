## Подсказка 3

`softmax(dim=0)` нормирует по оси токенов: оценка эксперта для токена зависит от логитов всех
токенов батча. Распределение должно быть по экспертам: `logits.softmax(dim=-1)`. Перенормировка
после top-k маскировала ошибку — сумма весов всё равно была 1.
