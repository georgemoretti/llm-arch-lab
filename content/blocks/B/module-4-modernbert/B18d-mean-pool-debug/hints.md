## Подсказка 1

Раз CLS pooling работает, а mean — нет, смотри в `mean_pool`. Возьми `h = torch.ones(1, 4, 2)`, поставь на позиции 2
и 3 любые другие числа (это PAD) и маску `[1, 1, 0, 0]`. Среднее настоящих токенов должно остаться `[1, 1]`.

## Подсказка 2

Скрытые состояния на PAD-позициях — не нули: энкодер считает их как для любого токена (PAD закрыт только как ключ).
Значит, в среднее их нужно не пустить.

## Подсказка 3

```python
m = attention_mask.to(hidden.dtype).unsqueeze(-1)          # [B, T, 1]
return (hidden * m).sum(1) / m.sum(1).clamp(min=1e-9)
```
Обрати внимание: если обнулить PAD, но делить на $T$, вектор только умножится на $L/T$, а после L2 направление то же.
Именно ненулевые векторы PAD портят направление.
