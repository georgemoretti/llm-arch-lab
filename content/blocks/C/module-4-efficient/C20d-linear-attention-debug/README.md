# Отладка: линейное внимание учится не тому, что генерирует

## Зачем это нужно

У линейного внимания две формы одной и той же формулы: параллельная (ей обучают) и рекуррентная (ей
генерируют). Если они расходятся, модель на инференсе работает не так, как на обучении, — причём ни одна
форма по отдельности не падает и выдаёт правдоподобные числа. Такие расхождения — классика при переносе
формул из «некаузальной» статьи в causal-код.

## Что поменялось относительно C20

Функции те же — `feature_map`, `linear_attention_noncausal`, `linear_attention`, `linear_attention_recurrent`.
Код написан кем-то другим, и в нём **одна** ошибка.

## Формула

$$o_t = \frac{\sum_{s\le t}\varphi(q_t)^\top\varphi(k_s)\,v_s}{\sum_{s\le t}\varphi(q_t)^\top\varphi(k_s)}$$

## Формы тензоров

```shapes
φ(q), φ(k) [B, H, T, d]
v [B, H, T, dv]
> линейное внимание
o [B, H, T, dv]

## состояние рекуррентной формы
S [B, H, d, dv]
z [B, H, d]
```

## Симптом

- некаузальная форма и рекуррентная форма совпадают с эталоном, кусочная генерация с переносом состояния
  тоже;
- параллельная causal-форма совпадает с рекуррентной **только в последней позиции**, а в начале
  последовательности её выходы заметно меньше по модулю;
- если все $v_s$ равны 3, параллельная форма выдаёт числа меньше 3, и чем ближе к началу, тем меньше;
- выход в позиции $t$ меняется, если изменить токены после $t$.
