# Дистилляция: мягкие метки, температура и ученик DistilBERT

## Зачем это нужно

bert-base — 110 М параметров и 12 слоёв. В проде это дорого: классификатор запросов или энкодер для поиска
вызывают тысячи раз в секунду. Маленькую модель можно обучить с нуля, но она выйдет заметно хуже. Дистилляция
(Hinton et al., 2015) обучает маленькую модель-**ученика** повторять выходы большой модели-**учителя**, а не только
правильные ответы.

Почему это работает лучше, чем обучение на тех же данных. Правильный ответ — один бит информации на пример: «здесь
должно быть слово *paris*». Распределение учителя рассказывает больше: *lyon* и *lille* правдоподобны, *banana* — нет.
В маленьких вероятностях спрятано, какие ответы модель считает похожими. Ученик получает эти сведения на каждом
токене, а не только на закрытых. Но при обычной температуре эти вероятности порядка $10^{-4}$ и почти не влияют
на лосс. Поэтому логиты обоих делят на **температуру** $T > 1$, распределение становится площе, и малые вероятности
начинают учитываться.

DistilBERT (Sanh et al., 2019) так сжала BERT: 6 слоёв вместо 12, на 40 % меньше параметров (66 М), на 60 %
быстрее, и 97 % качества BERT на GLUE (числа из статьи).

## Что поменялось относительно B10

| | обучение BERT (B10) | дистилляция DistilBERT (B12) |
|---|---|---|
| цель | правильный токен на закрытых позициях (MLM) | MLM **плюс** распределение учителя на всех позициях |
| лосс | cross-entropy | $\alpha_{ce} \cdot T^2\, \mathrm{KL} + \alpha_{mlm} \cdot \mathrm{CE} + \alpha_{cos} \cdot (1 - \cos)$ |
| модель | 12 слоёв × 768 | 6 слоёв × 768 (ширина та же), без `token_type_embeddings` и pooler |
| инициализация | случайная | слои учителя через один, эмбеддинги и голова — копии |
| учитель | — | bert-base, заморожен, только forward |

Размеры — из [config.json](https://huggingface.co/distilbert/distilbert-base-uncased/blob/main/config.json):
`n_layers = 6`, `dim = 768`, `n_heads = 12`, `hidden_dim = 3072`, `vocab_size = 30522`, `activation = "gelu"`.
Веса лоссов и температура — из скрипта обучения Hugging Face
([README и train.py](https://github.com/huggingface/transformers/tree/v4.30.0/examples/research_projects/distillation)):
`--alpha_ce 5.0 --alpha_mlm 2.0 --alpha_cos 1.0`, `temperature = 2.0` по умолчанию. Слои учителя там берутся с
номерами 0, 2, 4, 7, 9, 11 (`extract_distilbert.py`): «через один», но с концом стопки. В задаче по умолчанию —
строго 0, 2, 4, …, а номера можно передать.

## Формула

Логиты ученика $z$ и учителя $v$, температура $T$:

$$
q = \operatorname{softmax}(z / T), \qquad p = \operatorname{softmax}(v / T), \qquad
\mathcal{L}_{\text{soft}} = T^2 \cdot \frac{1}{N} \sum_{n=1}^{N} \sum_{c} p_{nc} \big(\log p_{nc} - \log q_{nc}\big).
$$

Зачем $T^2$. Градиент по логитам ученика:

$$
\frac{\partial \mathcal{L}_{\text{soft}}}{\partial z_{nc}} = \frac{T}{N}\,\big(q_{nc} - p_{nc}\big)
\;\approx\; \frac{1}{N V}\,\big(z_{nc} - v_{nc}\big) \quad \text{при больших } T
$$

(для логитов с нулевым средним). Без множителя $T^2$ градиент мягкой части убывал бы как $1/T^2$, и при смене
температуры пришлось бы заново подбирать $\alpha$. С ним масштаб от $T$ почти не зависит, а при больших $T$ дистилляция
превращается в подгонку логитов: ученик повторяет логиты учителя.

Смесь (Hinton et al.): $\;\mathcal{L} = \alpha\, \mathcal{L}_{\text{soft}} + (1 - \alpha)\, \operatorname{CE}(z, y)$; мягкая часть — по
всем позициям, жёсткая — только там, где есть метка ($y \ne -100$). Выравнивание скрытых состояний (DistilBERT):

$$
\mathcal{L}_{\cos} = \frac{1}{|M|} \sum_{t \in M} \big(1 - \cos(h^{S}_t, h^{T}_t)\big), \qquad M = \{t : \text{attention\_mask}_t = 1\}.
$$

Косинус возможен потому, что ширина ученика и учителя одна (768). Будь ученик уже, понадобилась бы проекция.

## Формы тензоров

```shapes
input_ids [B, T]
fork
> учитель (12 слоёв, no_grad)
v [B, T, V]
branch
> ученик (6 слоёв)
z [B, T, V]
join
> reshape → [N, V], N = B·T; softmax(· / T)
p, q [N, V]
> Σ_c p·(log p − log q), mean по N, × T²
loss_soft []
> + CE по позициям с labels ≠ −100; + (1 − cos) по mask = 1 на h [B, T, H]
loss []
axis V:wide = 30 522
axis H = 768 у обоих
```

## Задание

В `solution.py` (рабочая копия в `workspace/B12-distillation/`):

1. `soft_targets(logits, T)` — $\operatorname{softmax}(z / T)$.
2. `distill_kl(student_logits, teacher_logits, T)` — $T^2 \cdot \mathrm{KL}(p \,\|\, q)$, среднее по строкам, логиты любой формы
   `[..., V]`; учитель не получает градиент.
3. `distillation_loss(student_logits, teacher_logits, labels, T, alpha)` — смесь мягкой и жёсткой частей.
4. `hidden_cosine_loss(student_hidden, teacher_hidden, attention_mask)` — $1 - \cos$ по настоящим токенам.
5. `student_from_teacher(teacher, layers=None)` — новый `BertForMaskedLM` (B10) с меньшим числом слоёв, веса
   скопированы из учителя.

## Критерии готовности

- с ростом $T$ мягкие метки площе, порядок классов не меняется;
- `distill_kl` = `F.kl_div(…, reduction="batchmean")` · $T^2$ при $T$ = 1, 2, 5; 0 при совпадении; форма `[B, T, V]`
  работает как `[N, V]`;
- градиент по логитам ученика равен $T (q - p) / N$, до учителя не доходит, его масштаб при $T = 8$ и $T = 2$ одного
  порядка;
- смесь: `alpha = 1` — только мягкая часть по всем позициям, `alpha = 0` — только CE с `ignore_index = −100`, без меток —
  не nan;
- cosine-loss не зависит от масштаба векторов и от значений на PAD;
- ученик — `BertForMaskedLM` со слоями 0, 2, … учителя (или заданными), копиями весов и связанной головой; правка
  ученика не меняет учителя;
- ученик из слоёв учителя стартует ближе случайного, а за 60 шагов дистилляции KL падает в 4+ раза и top-1 совпадает
  с учителем на ≥ 80 % позиций.

Запуск: `llmlab test B12-distillation`.
