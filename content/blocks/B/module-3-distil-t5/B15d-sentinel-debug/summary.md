## TL;DR

`prev_is_noise` дополнялся слева единицей вместо нуля. Для входа это незаметно (маска начинается с текста), а в цели
первый спан на позиции 0 считался продолжением спана «до начала»: его выбрасывали без sentinel, и все sentinel-ы цели
съехали на один кусок. Модель училась бы ставить sentinel после своего куска. Ловится обратной операцией «собрать
текст из входа и цели» и проверкой длины цели.

## Формула

$$\text{prev}_0 = \text{False},\ \text{prev}_t = m_{t-1};\quad \text{first} = m \wedge \neg\,\text{prev}$$

## Формы тензоров

```
~noise_mask [L] → first / rest → sentinel на first, выкинуть rest → targets
```

## Что поменялось относительно B15

Ничего в механизме: граничное значение сдвига маски. Опасно именно потому, что вход остаётся правильным.
