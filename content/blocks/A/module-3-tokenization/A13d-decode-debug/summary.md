## TL;DR

Если декодировать каждый токен отдельно, символ, байты которого попали в разные токены, превращается в
несколько «�». На английском тексте это почти не видно, на русском, эмодзи и иероглифах — сразу.
Правильно: склеить байты всех токенов (и спецтокенов) и декодировать UTF-8 один раз.

## Формула

$$\text{ошибка: } \Vert_j\, \operatorname{utf8}^{-1}(\text{vocab}[t_j]) \quad\text{вместо}\quad \operatorname{utf8}^{-1}\big(\Vert_j\, \text{vocab}[t_j]\big)$$

## Формы тензоров

```
ids [n] → bytes каждого токена → join → один decode (а не decode каждого → join)
```

## Что поменялось относительно A13

Ничего в механизме: найден decode по токенам вместо decode всей последовательности байтов. При потоковой
генерации (токен за токеном) та же проблема решается буфером: неполный символ ждёт следующих байтов.
