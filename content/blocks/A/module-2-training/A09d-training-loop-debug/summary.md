## TL;DR

Без `zero_grad` градиенты копятся: шаг на $t$-м батче делается по сумме градиентов всех прошлых шагов,
посчитанных в старых точках. На полном датасете это выглядит как странный momentum, и обучение всё
равно как-то идёт. Smoke-тест «переобучись на одном батче» ловит ошибку сразу.

## Формула

$$\text{без zero\_grad: } g_t = \sum_{s \le t} \nabla L(\theta_s) \quad\text{вместо}\quad g_t = \nabla L(\theta_t)$$

## Формы тензоров

```
p.grad — форма параметра; backward() прибавляет к нему, zero_grad() сбрасывает
```

## Что поменялось относительно A09

Ничего в механизме: найден пропущенный `zero_grad`. Найден он smoke-тестом, а не по кривой обучения.
