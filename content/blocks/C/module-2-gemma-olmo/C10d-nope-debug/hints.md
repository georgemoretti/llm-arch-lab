`rope_layers(8, 4)` и сравни с первыми восемью числами `no_rope_layers` из config.json SmolLM3:
`[1, 1, 1, 0, 1, 1, 1, 0]` (1 = RoPE есть).

Число NoPE-слоёв совпадает, а их места — нет. Какой слой в группе из четырёх должен быть без RoPE —

## Подсказка 3

`i % interval != 0` делает NoPE-слоями 0, 4, 8, … — первые в группах. У SmolLM3 NoPE — последние:
`(i + 1) % interval != 0` → NoPE на 3, 7, 11, … Та же ловушка — с global-слоями Gemma в C07.
