## Подсказка 1

Численная производная по одному элементу: сдвинь только его, посчитай $f$ дважды (с $+h$ и $-h$),
раздели разность на $2h$. Для тензора повтори это для каждого элемента. Сначала сделай копию, чтобы
не испортить вход: `x = x.detach().clone()`.

## Подсказка 2

Удобно работать с плоским видом той же памяти: `flat = x.view(-1)` — изменение `flat[i]` меняет
`x`, а `f(x)` видит сдвиг. Не забудь вернуть исходное значение элемента перед переходом к
следующему. Результат пиши в `grad = torch.zeros_like(x)` через `grad.view(-1)[i]`.

## Подсказка 3

`rel_error`: `denom = torch.maximum(torch.maximum(a.abs(), b.abs()), torch.full_like(a, eps))`,
затем `((a - b).abs() / denom).max().item()`. В `check_value_grads` числовая функция строит **новые**
`Value` из элементов тензора: `fn(*[Value(v) for v in t.tolist()]).data`.
