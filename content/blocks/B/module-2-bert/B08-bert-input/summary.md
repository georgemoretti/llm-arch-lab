## TL;DR

BERT получает пару текстов одной последовательностью: `[CLS] a [SEP] b [SEP]`. `token_type_ids` (0 у первого
сегмента вместе с его `[SEP]`, 1 у второго) выбирают эмбеддинг сегмента. Вход слоя — LayerNorm суммы трёх
эмбеддингов: токен + обучаемая позиция + сегмент. Длинная пара обрезается `longest_first`: короткий сегмент цел,
если он не длиннее половины бюджета, иначе бюджет пополам. `attention_mask` (1/0) станет padding-маской по ключам.

## Формула

$$x_t = \operatorname{LN}(E_w[\text{id}_t] + E_p[t] + E_s[\text{type}_t])$$

## Формы тензоров

```
[CLS] a [SEP] b [SEP] → input_ids, token_type_ids, attention_mask [B,T] → LN(w + p + s) → [B,T,H]
```

## Что поменялось относительно B02

Синусоиды заменены обучаемыми позициями, появились эмбеддинг сегмента и служебные `[CLS]` / `[SEP]`; вместо
пары «источник → цель» в двух стеках — пара текстов в одной последовательности.
