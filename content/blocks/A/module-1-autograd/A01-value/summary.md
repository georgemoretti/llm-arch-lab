## TL;DR

Autograd запоминает граф прямого прохода: у каждого узла есть входы и локальные производные по ним.
Обратный проход идёт в обратном топологическом порядке. Он начинает с `L.grad = 1` и передаёт
каждому входу вклад `local · node.grad`. Вклады от нескольких потребителей **складываются**. Обход
делается без рекурсии, потому что графы бывают глубокими.

## Формула

$$\frac{\partial L}{\partial v} = \sum_{u \,\in\, \text{потребители}(v)} \frac{\partial L}{\partial u}\,\frac{\partial u}{\partial v}$$

## Формы тензоров

```
скаляры: Value(data, grad, _children, _local_grads)
w, x → (*) → wx → (+ b) → z → tanh → L;  backward: L.grad = 1 → z → wx, b → w, x
```

## Что поменялось относительно ручного дифференцирования

Производная всей функции больше не выводится на бумаге. Каждая операция знает только свои
локальные производные, а chain rule применяется автоматически в цикле по графу. Градиент по всем
входам стоит одного обратного прохода.
