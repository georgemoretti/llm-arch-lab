# Отладка: модель отвечает на вопросы, но ответы иногда обрывки

## Зачем это нужно

Extractive QA (как в SQuAD) не генерирует ответ, а показывает его в тексте: модель выдаёт для каждого токена
оценку «здесь начинается ответ» и «здесь заканчивается». Превратить две оценки в один ответ — отдельная задача
постобработки. На уверенной модели почти любой способ работает: оба пика стоят в одном месте. Ошибки вылезают на
трудных вопросах, где оценки размазаны, — то есть там, где ответ важнее всего.

## Что поменялось относительно B11

Ничего: это те же функции, что в B11. Их написал кто-то другой, и в коде **одна** ошибка.

## Формула

Ответ — пара позиций, у которой лучшая **сумма** оценок среди допустимых:

$$
(\hat\imath, \hat\jmath) = \arg\max_{\substack{i \le j < i + L \\ i, j \in \text{контекст}}} \big(s_i + e_j\big).
$$

## Формы тензоров

```shapes
start_logits [B, T]
end_logits [B, T]
context_mask [B, T] — True у токенов абзаца
> best_span
start [B]
end [B]
```

`SequenceClassifier`, `align_labels` и `qa_loss` в порядке.

## Симптом

- если оценки начала и конца резко выражены в одном месте, ответ верный;
- ответ всегда внутри абзаца и не длиннее `max_answer_len`;
- но на «неуверенных» логитах (тест: 1000 случайных примеров, $T = 64$, $L = 15$) в половине случаев конец
  оказывается **раньше** начала — ответ пустой, а в 74 % случаев пара не совпадает с лучшей допустимой.
