# C10. NoPE: слои без позиционного кодирования

## Зачем это нужно

RoPE (C03) кодирует позицию поворотом q и k. Это работает, но у него есть известная слабость: на
длинах, которых модель не видела при обучении, углы поворота «незнакомые», и качество падает.
Отсюда все приёмы с увеличением θ и масштабированием частот при расширении контекста.

Неожиданный факт: декодеру позиционное кодирование **не обязательно**. Causal-маска уже несёт
информацию о позиции — запрос на позиции $t$ видит ровно $t + 1$ ключей, поэтому, например, вес
первого токена в softmax зависит от $t$. Kazemnejad et al. (2023) показали, что декодер без
позиционного кодирования (NoPE) теоретически может восстановить и абсолютные, и относительные
позиции, а в их экспериментах на небольших моделях обобщался на более длинные последовательности
лучше, чем варианты с RoPE и другими кодированиями.

Совсем без RoPE большие модели не делают — но **смешивают**: часть слоёв с RoPE, часть без.
SmolLM3 (Hugging Face, 2025) убирает RoPE из каждого 4-го слоя: авторы ссылаются на работу
Yang et al. (2025) и пишут, что в их абляциях это улучшило длинный контекст, не ухудшив короткий.
Похожую схему ещё раньше применили в Llama 4 (там NoPE-слои — глобальные, а RoPE-слои работают
локальными кусками) — это показывает, что идея прижилась, но детали Llama 4 в этой задаче не
используются.

## Что поменялось относительно C05

| | C05 (`LlamaAttention`) | C10 (`NoPEAttention`) |
|---|---|---|
| RoPE | в каждом слое | только если `use_rope=True` |
| causal-маска | есть | есть **всегда** — именно она даёт NoPE-слою информацию о позиции |
| расписание слоёв | все одинаковые | `rope_layers(n, interval)`: каждый `interval`-й слой — NoPE |
| параметры | — | новых нет: NoPE-слой — тот же attention минус поворот |

Нумерация как у Gemma в C07: слой $i$ (с 0) — NoPE, если $(i + 1) \bmod \text{interval} = 0$, то есть
последний в каждой группе. У SmolLM3-3B: 36 слоёв, interval = 4 → NoPE-слои 3, 7, 11, …, 35.
В `config.json` это записано списком `no_rope_layers = [1, 1, 1, 0, …]`, где, несмотря на имя,
**1 означает «RoPE есть»** (`use_rope = no_rope_layers[layer_idx]` в `modeling_smollm3.py`).

## Формула

RoPE-слой: $\text{score}_{ij} = (R_i q_i) \cdot (R_j k_j) / \sqrt{D}$. NoPE-слой:
$\text{score}_{ij} = q_i \cdot k_j / \sqrt{D}$. В обоих маска $j \le i$.

Почему NoPE-слой знает позицию. Пусть токен 0 — особый (например, BOS), а токены $1..t$ одинаковые
(одинаковые $k$ и $v$, score $s$). Тогда для запроса на позиции $t$

$$
\text{out}_t = \frac{e^{s_0} v_0 + t\,e^{s} v}{e^{s_0} + t\,e^{s}},
$$

и это разные векторы для разных $t$: вес $v_0$ убывает как $\approx 1/t$. Без маски все $t$ видели
бы одно и то же множество ключей, и выходы совпали бы.

Обратная сторона: для **последнего** токена NoPE-слой — «мешок слов». Он видит все предыдущие
ключи, а softmax-сумма не зависит от их порядка: перестановка токенов $0..T-2$ выход последнего
токена не меняет. Порядок модель узнаёт из RoPE-слоёв и из того, что промежуточные позиции видят
разные префиксы.

## Формы тензоров

```
x                       [B, T, C]
q                       [B, H, T, D]     ── RoPE, только если use_rope
k, v                    [B, H_kv, T, D]  ── RoPE на k, только если use_rope
repeat_kv               [B, H, T, D]
scores                  [B, H, T, T]     + causal-маска (всегда)
out                     [B, T, C]

rope_layers(36, 4) = [T, T, T, F, T, T, T, F, …]     (True = RoPE)
build_attention_layers(…) → nn.ModuleList[NoPEAttention] с use_rope по расписанию
```

## Задание

В `solution.py` (рабочая копия в `workspace/C10-nope/`) реализуй:

1. `rope_layers(n_layers, no_rope_layer_interval)` → `list[bool]`, True = слой с RoPE;
2. `NoPEAttention.forward(x)` — GQA + causal-маска; RoPE только при `self.use_rope`
   (конструктор дан, как в C05);
3. `build_attention_layers(n_layers, d_model, n_heads, n_kv_heads, interval, rope_theta)` →
   `nn.ModuleList` из `NoPEAttention` по расписанию.

## Критерии готовности

- расписание совпадает с `no_rope_layers` из config.json SmolLM3-3B; крайние случаи: interval > n
  (RoPE везде) и interval = 1 (NoPE везде);
- RoPE-слой совпадает с `LlamaAttention`, NoPE-слой — с оракулом без поворота;
- NoPE: перестановка предыдущих токенов не меняет выход последнего, а RoPE-слой — меняет;
- NoPE + маска: одинаковые токены на разных позициях дают разные выходы; будущее не протекает;
- стек из 8 слоёв с interval = 4: NoPE — слои 3 и 7.
