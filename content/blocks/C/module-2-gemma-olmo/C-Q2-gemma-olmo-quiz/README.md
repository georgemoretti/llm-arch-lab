# Квиз модуля: Gemma 3 / OLMo 2 / SmolLM3

## Зачем это нужно

Модуль 1 превратил GPT-2 в Llama. Модуль 2 — про то, что поменялось **после** Llama: как сделать
длинный контекст дешевле (sliding window, local:global, кольцевой кеш), как сделать обучение
стабильнее (место нормы, QK-Norm) и можно ли обойтись без позиционного кодирования (NoPE). Квиз
собирает вопросы по всем задачам модуля: с вариантами ответа и открытые.

## Что поменялось относительно Llama — в одной таблице

Проверь, что можешь объяснить каждую строку, не подглядывая в задачи.

| | Llama 3 | Gemma 3 | OLMo 2 | SmolLM3 | задача |
|---|---|---|---|---|---|
| маска attention | causal | 5 sliding (окно 1024) : 1 full | causal | causal | C07 |
| место нормы | Pre-Norm | sandwich (до и после подслоя) | на выходе подслоя внутри остатка | Pre-Norm | C08 |
| QK-Norm | нет | по голове | по всей проекции | нет | C09 |
| позиции | RoPE во всех слоях | RoPE, θ = 10K local / 1M global | RoPE во всех слоях | каждый 4-й слой — NoPE | C10 |
| KV-cache | растёт с контекстом | sliding-слои — кольцевой буфер на 1024 | растёт | растёт | C11 |

Источники чисел — config.json моделей на Hugging Face (ссылки в task.yaml задач).

## Как проходить

1. Открой вкладку **«Вопросы»**.
2. Для вопросов с вариантами — выбери ответ, сразу увидишь, верно ли, и объяснение.
3. Для открытых — сначала ответь сам (лучше письменно, 2–4 предложения), затем открой эталон и
   честно оцени: всё ли главное ты назвал.
4. Ответил неуверенно — вернись к задаче из таблицы выше, её конспект во вкладке «Конспекты».

Сейчас прогресс по квизу не сохраняется. Флеш-карточки и интервальное повторение (SM-2) появятся в
Фазе 7 (вкладка Interview).
