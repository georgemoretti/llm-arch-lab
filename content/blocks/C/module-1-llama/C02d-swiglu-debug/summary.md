## TL;DR

Баг: SiLU стояла на ветке `up_proj`, а не на `gate_proj`. У матриц одинаковые формы, поэтому
код работает и даже обучается с нуля — сломана только совместимость с весами Llama. Найти
помогает свойство формулы: выход линеен по `up_proj`, а закрытый `gate_proj` даёт ноль.

## Формула

$$\text{верно: } W_{\text{down}}(\operatorname{SiLU}(W_{\text{gate}}x) \odot W_{\text{up}}x) \qquad \text{баг: } W_{\text{down}}(W_{\text{gate}}x \odot \operatorname{SiLU}(W_{\text{up}}x))$$

## Формы тензоров

```
x [B,T,C] → gate_proj → silu ─┐
x [B,T,C] → up_proj ──────────⊙→ [B,T,F] → down_proj → [B,T,C]
```

## Что поменялось относительно C02

Ничего в архитектуре — урок про отладку: при одинаковых формах «перепутанные» параметры не
ловятся ни формами, ни обучением с нуля. Ловят их проверки свойств (линейность ветки) и
сравнение с эталоном на одних весах.
