# Mamba-2 (SSD): скан состояния == attention с затухающей маской

*Задача повышенной сложности, необязательная.*

## Зачем это нужно

State space models (S4, Mamba) пришли из теории управления: скрытое состояние $h$ эволюционирует по
линейному закону, вход «вливается» в него, выход «читается» из него. Mamba (2023) сделала параметры
**селективными** — зависящими от текущего токена; по данным авторов, это впервые позволило SSM сравняться
с трансформерами по качеству на языке при линейной стоимости.

Mamba-2 (Dao, Gu, ICML 2024) упростила матрицу перехода до **скаляра на голову** — $A_t = e^{\Delta_t A}$ — и
показала **двойственность** (state space duality, SSD): та же модель записывается двумя способами.

- **Рекуррентно** (скан): состояние $h_t$ фиксированного размера, по токену за шаг — для генерации.
- **Квадратично** — как attention: матрица $[T, T]$ «запрос × ключ» $C_t \cdot B_s$, умноженная на
  causal-маску с **затуханием** $L_{ts} = \prod_{r=s+1}^{t} e^{\Delta_r A}$ — для обучения на GPU.

То есть Mamba-2 — это линейное внимание (C20) без нормировки, но с гейтом забывания: ровно та «gated»
половина, которую Gated DeltaNet (C21) соединяет с правилом дельты. В реальной реализации обе формы
смешивают: квадратичная внутри кусков, рекуррентная между ними (`ssd_minimal.py`; в классе `Mamba2`
по умолчанию `chunk_size = 256`).

## Что поменялось относительно C20

| | C20 (линейное внимание) | C23 (Mamba-2 / SSD) |
|---|---|---|
| «ключ», «запрос», «значение» | $\varphi(k_s)$, $\varphi(q_t)$, $v_s$ | $B_s$, $C_t$ (общие для всех голов), $\Delta_s x_s$ |
| запись в состояние | $S \mathrel{+}= \varphi(k) v^\top$ | $h \leftarrow e^{\Delta_t A} h + \Delta_t B_t x_t^\top$ — с затуханием |
| маска в параллельной форме | causal из единиц | $L_{ts} = \exp(\sum_{r=s+1}^{t} \Delta_r A)$ — затухает с расстоянием |
| нормировка | деление на $\varphi(q)^\top z$ | нет |
| прочее | — | skip-связь $D \cdot x_t$ |

## Формула

Для каждой головы ($x_t \in \mathbb{R}^{P}$, $B_t, C_t \in \mathbb{R}^{N}$, $\Delta_t > 0$, $A < 0$):

$$
h_t = e^{\Delta_t A}\, h_{t-1} + \Delta_t\, B_t\, x_t^\top \in \mathbb{R}^{N \times P},
\qquad
y_t = h_t^\top C_t + D\, x_t
$$

Развернём рекуррентность: $h_t = \sum_{s \le t} \big(\prod_{r=s+1}^{t} e^{\Delta_r A}\big) \Delta_s B_s x_s^\top$, откуда

$$
y_t = \sum_{s \le t} \underbrace{\exp\!\Big(\sum_{r=s+1}^{t} \Delta_r A\Big)}_{L_{ts}} \,(C_t \cdot B_s)\, \Delta_s x_s + D x_t,
\qquad
L = \exp(\operatorname{segsum}(\Delta A))
$$

`segsum(a)[t, s]` $= a_{s+1} + \dots + a_t$ при $s \le t$ (на диагонали — пустая сумма, 0) и $-\infty$ при $s > t$, чтобы
$\exp$ дал 0. Здесь он считается как $\text{cumsum}_t - \text{cumsum}_s$ — просто, но на длинных последовательностях
теряет точность; в `ssd_minimal.py` есть устойчивый вариант через маскированный cumsum.

## Формы тензоров

```shapes
x [b, T, H, P]
dt [b, T, H] — Δ > 0
A [H] — < 0
B, C [b, T, N] — общие для всех голов
D [H]

## ssd_recurrent, шаг t
> decay = exp(dt[:, t] · A)
decay [b, H]
> write = dt[:, t] · (B[:, t] ⊗ x[:, t])
write [b, H, N, P]
> h = decay · h + write
h [b, H, N, P]
> y_t = Σ_N C[:, t] · h + D · x[:, t]
y_t [b, H, P]

## ssd_quadratic: то же самое как attention
fork
> exp(segsum(dt · A)) — dt · A → [b, H, T]
L [b, H, T, T] — затухающая causal-маска
branch
> C · Bᵀ
scores [b, T, T]
join L ⊙ scores
M [b, H, T, T]
> einsum("bhts,bshp->bthp", M, dt · x) + D·x
y [b, T, H, P]
axis N:hdim = размер состояния
axis P = размер канала головы
axis H = головы
axis T = время
```

## Задание

В `solution.py` (рабочая копия в `workspace/C23-mamba2-ssd/`) реализуй `segsum(a)`,
`ssd_recurrent(x, dt, A, B, C, D, state=None)` → `(y, state)` и `ssd_quadratic(x, dt, A, B, C, D)`.
Упрощения: нет проекций слоя (in_proj, свёртка, выходной гейт с RMSNorm), $\Delta$, $B$, $C$ подаются готовыми,
одна группа $B/C$ на все головы (`ngroups = 1`, как по умолчанию в Mamba-2).

## Реальные числа

Mamba-2 2.7B (`config.json` + значения по умолчанию класса `Mamba2` в `mamba_ssm`): 64 слоя, $d_{\text{model}} = 2560$,
`expand = 2` → 5120 каналов, `headdim = 64` → 80 голов, `d_state` $N = 128$. Состояние слоя — $80 \cdot 128 \cdot 64 = 655\,360$
чисел при любой длине контекста.

## Критерии готовности

- `segsum`: суммы $a_{s+1..t}$ под диагональю, 0 на диагонали, $-\infty$ над ней;
- скан совпадает с формулой; кусками с переносом состояния — как целиком;
- квадратичная форма совпадает со сканом и не пропускает будущее;
- при $A = 0$, $D = 0$ обе формы дают causal линейное внимание без нормировки ($q = C$, $k = B$, $v = \Delta x$).
