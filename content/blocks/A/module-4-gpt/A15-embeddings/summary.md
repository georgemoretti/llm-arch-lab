## TL;DR

Трансформер обрабатывает все позиции одними весами, поэтому порядок нужно передать явно: к эмбеддингу
токена прибавляется обучаемый эмбеддинг позиции (`wte(idx) + wpe(arange(T))`, broadcasting по батчу).
Позиций не больше `block_size`. Weight tying: выходной слой использует ту же матрицу $[V, C]$, что и
входные эмбеддинги. Это один параметр, градиенты двух путей складываются, параметров меньше на $V \cdot C$.
Стартовый loss при малых весах ≈ $\ln V$. Это первая проверка любой языковой модели.

## Формула

$$h_t = E_{x_t} + P_t,\qquad \text{logits}_t = h_t E^{\top},\qquad \mathcal{L}_0 \approx \ln V$$

## Формы тензоров

```
idx [B,T] → wte [B,T,C] + wpe(arange T) [T,C] → h [B,T,C] → h @ wteᵀ → logits [B,T,V] → CE по [B·T]
```

## Что поменялось относительно A10

Вместо окна фиксированной длины — вся последовательность и предсказание на каждой позиции; порядок
передаётся вектором позиции, а не склейкой; выходной слой связан с эмбеддингами.
