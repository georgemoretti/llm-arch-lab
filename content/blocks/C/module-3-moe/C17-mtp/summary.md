## TL;DR

MTP добавляет $D$ модулей, предсказывающих токены дальше следующего: глубина $k$ — токен $t_{i+k+1}$.
В DeepSeek-V3 $D = 1$, модули идут цепочкой: глубина $k$ смешивает (через `eh_proj`) нормированные
эмбеддинг известного токена $t_{i+k}$ и скрытое состояние глубины $k-1$, прогоняет через блок
трансформера и использует общие с основной моделью эмбеддинг и выходную голову. Loss —
$L_{\text{main}} + \frac{\lambda}{D}\sum L_k$ ($\lambda$ = 0.3 → 0.1). Даёт более плотный сигнал обучения и
дешёвого «черновика» для спекулятивного декодирования; при обычном инференсе модули отбрасываются.

## Формула

$$h^k_i = \operatorname{Block}_k\big(W_{eh}[\operatorname{norm}(\operatorname{Emb}(t_{i+k})) ; \operatorname{norm}(h^{k-1}_i)]\big),\quad
L = L_{\text{main}} + \frac{\lambda}{D}\sum_{k=1}^{D} \operatorname{CE}(h^k_i \to t_{i+k+1})$$

## Формы тензоров

```
глубина k: h[:, :T−k] [B,T−k,C] + embed(tokens[:, k:]) → [B,T−k,2C] → eh_proj → block → lm_head → [B,T−k,V]
L_k = CE(logits_k[:, :−1], tokens[:, k+1:])
```

## Что поменялось относительно C06

Архитектура основной модели та же; при обучении к ней добавлены MTP-модули (общие эмбеддинг и голова)
и дополнительные слагаемые loss.
