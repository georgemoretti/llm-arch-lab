## Подсказка 1

Вход и цель строит одна и та же функция `noise_span_to_unique_sentinel`, только цель — с маской `~noise_mask`. Вход
верный, цель — нет. Чем отличаются две маски на позиции 0?

## Подсказка 2

Маска шума начинается с текста: `noise_mask[0] = False`, значит `(~noise_mask)[0] = True`. Для цели первый «спан» —
это начало текста, он начинается на позиции 0. Посмотри, что функция считает «предыдущим токеном» для позиции 0.

## Подсказка 3

До начала текста шума нет: `prev_is_noise` на позиции 0 должен быть `False` (`noise_mask.new_zeros(1)`). С единицей
спан на позиции 0 считается продолжением несуществующего спана: его токены выкидываются без sentinel, и нумерация
сдвигается на один.
