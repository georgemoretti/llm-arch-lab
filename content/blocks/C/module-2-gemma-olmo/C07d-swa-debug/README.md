# C07d. Отладка: sliding window пропускает лишний токен

## Зачем это нужно

Ошибка «на единицу» в маске — самая частая ошибка в SWA, и она коварна: модель работает, loss
выглядит нормально, но веса, обученные с одним окном, загружены в код с другим. Расхождение с
эталонной реализацией маленькое (один лишний токен из тысячи) и копится по слоям. А при SWA с
кольцевым кешем (C11) лишнего токена в буфере уже нет, и прогон с кешем начинает расходиться с
прогоном без кеша.

## Что поменялось относительно C07

Архитектура та же — `sliding_window_mask`, `layer_types`, `SlidingWindowAttention` из C07. Код
написан кем-то другим, и в нём **одна** ошибка.

## Формула

$$M_{p,j} = 0 \iff 0 \le p - j < W$$

## Формы тензоров

```
q_pos [T, 1], k_pos [1, S] → mask [T, S] → scores [B, H, T, T] + mask → out [B, T, C]
```

Формы правильные, расписание слоёв правильное, RoPE и GQA правильные.

## Симптом

- causal соблюдается: будущее не протекает;
- при `window=None` и `window ≥ T` всё совпадает с `LlamaAttention`;
- но при окне `W` выход в позиции `t` меняется, если изменить токен `t − W` — а он уже за
  пределами окна. При `window=1` токен видит не только себя.
