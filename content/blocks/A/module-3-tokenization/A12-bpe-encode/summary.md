## TL;DR

Encode переводит текст в байты и сливает пары **по рангу**: каждый раз пару, выученную раньше всех
(наименьший id в `merges`), а не самую частую в этом тексте. Так обучающий текст кодируется ровно как при
обучении, а один и тот же кусок текста — всегда одинаково. Decode сначала склеивает байты всех токенов и
только потом один раз декодирует UTF-8 с `errors="replace"`: токен может быть половиной символа.

## Формула

$$(a,b)^* = \arg\min_i r(x_i, x_{i+1}),\qquad \operatorname{decode}(t) = \operatorname{utf8}^{-1}\big(\Vert_j\, \text{vocab}[t_j]\big)$$

## Формы тензоров

```
text → bytes [n] → (min rank → merge_pair)* → ids [n′];  ids → bytes join → utf-8 decode (replace) → text
```

## Что поменялось относительно A11

Обучение выбирает самую частую пару, кодирование — самую раннюю по рангу. Частоты нового текста в
encode не участвуют вовсе.
