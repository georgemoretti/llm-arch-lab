# Проект: мини-GPT на символах корпуса курса

## Зачем это нужно

Все детали готовы: эмбеддинги с позициями (A15), attention с маской (A16), блок трансформера (A17),
цикл обучения (A09), языковая модель на символах (A10). В этом проекте они собираются в настоящую GPT.
Она маленькая (около 190 тысяч параметров) и обучается на корпусе курса меньше чем за минуту на
обычном ноутбуке. Устройство у неё то же, что у GPT-2. Отличий три: одна голова attention вместо
двенадцати (C00), словарь из символов вместо BPE (A11–A14) и размеры в тысячи раз меньше.

После этого проекта блок C читается как список изменений к тому, что ты уже построил своими руками.

## Что поменялось относительно A10

| | A10 (MLP на окне) | A18 (мини-GPT) |
|---|---|---|
| контекст | 4 символа | до `block_size` = 64 символов |
| как смешиваются позиции | склейка окна | attention, веса по содержимому |
| глубина | один скрытый слой | `n_layer` блоков с остатками и LayerNorm |
| предсказаний за проход | одно | `T` — на каждой позиции |
| выходной слой | свой | связан с эмбеддингами |
| генерация | окно сдвигается | контекст обрезается до последних `block_size` токенов |

## Формула

$$
h^{(0)} = E_{x} + P,\qquad
h^{(l)} = \operatorname{Block}_l\big(h^{(l-1)}\big),\qquad
\text{logits} = \operatorname{LN}_f\big(h^{(L)}\big)\, E^{\top},
$$

$$
\mathcal{L} = \frac{1}{BT}\sum_{b,t} -\log p_\theta\big(x_{b,t+1} \mid x_{b,\le t}\big).
$$

Батч — случайные куски текста длины $T$: вход $x = \text{data}[s : s+T]$, цель
$y = \text{data}[s+1 : s+T+1]$. Каждый кусок даёт $T$ примеров сразу: позиция $t$ учится предсказывать
символ $t+1$, видя только символы $0 \dots t$ (маска A16).

Генерация повторяет один шаг: подать последние `block_size` токенов, взять логиты последней позиции,
поделить на температуру $\tau$, выбрать токен из $\operatorname{softmax}(\text{logits}/\tau)$ и дописать.
При $\tau = 0$ берётся argmax.

## Формы тензоров

```shapes
## обучение
- data [N] — индексы символов корпуса
> get_batch: B случайных начал s
x [B, T] — data[s : s + T]
y [B, T] — data[s + 1 : s + T + 1]
> emb: wte + wpe
h [B, T, C]
> n_layer × Block (A17)
h [B, T, C]
> ln_f → lm_head (= wteᵀ)
logits [B, T, V]
> cross_entropy с y
loss []
## генерация
idx [B, t]
> последние block_size токенов → модель → logits[:, −1] / τ → softmax → multinomial
idx [B, t + 1]
axis C = n_embd
axis V = 67 символов
```

## Задание

В `solution.py` (рабочая копия в `workspace/A18-minigpt/`):

1. `MiniGPT.forward(idx, targets=None)` → `(logits, loss)`: эмбеддинги → блоки → `ln_f` → `lm_head`.
2. `MiniGPT.generate(idx, max_new_tokens, temperature=1.0, generator=None)`.
3. `get_batch(data, block_size, batch_size, generator)` → `(x, y)`.
4. `train(model, data, steps, batch_size, lr, generator)` → список лоссов. AdamW
   (`weight_decay=0.01`), каждый шаг: батч → loss → `zero_grad` → `backward` →
   `clip_grad_norm_(…, 1.0)` → `step`.

Конструктор, `estimate_loss` и `main` готовы. Детали A15–A17 импортированы из эталонов.

Когда тесты пройдут, обучи модель целиком:

```bash
python workspace/A18-minigpt/solution.py        # ~30 с на CPU
```

Скрипт каждые 100 шагов печатает train/val-лосс и образец текста. Он останавливается, когда val три
проверки подряд не улучшается, и показывает генерацию лучшей модели. На корпусе курса лучший val около
2.25 (перплексия ≈ 9.5) достигается примерно на 1000-м шаге. Модель уже пишет настоящие слова
(«модель», «обучения», «каждой», «Поэтому»), но фразы пока бессвязные.

## Почему так мало и что будет дальше

Обучающий текст — около 21 тысячи символов. Модели из 190 тысяч параметров этого хватает, чтобы
выучить текст почти наизусть. На визуализации видно, как после ~1000 шагов train-лосс продолжает падать,
а val растёт: модель перестаёт обобщать и начинает заучивать. С этим борются тремя способами: больше
данных (главный), dropout и weight decay, ранняя остановка. Здесь используется третий.

Проверь сам: добавь в корпус свой текст и посмотри, на сколько отодвинется минимум val. Или поставь
`pre_norm=False` в `MiniGPTConfig` и сравни, как обучается post-LN.

## Критерии готовности

- логиты и loss совпадают с эталоном для pre-LN и post-LN; не пропущен финальный `ln_f`;
- стартовый loss ≈ $\ln 67 \approx 4.20$; логиты позиции $t$ не зависят от токенов после $t$;
- `get_batch`: `y` — `x` со сдвигом на 1, куски непрерывные, крайние начала достижимы, конец данных не
  превышен, случайность только из `generator`;
- `train` повторяет историю лоссов эталона за 40 шагов, лосс падает;
- на одном батче модель доходит почти до нулевого лосса за 150 шагов;
- `generate`: форма `[B, T + n]`, жадный выбор и сэмплирование как у эталона, генерация длиннее
  `block_size` работает, режим модели восстанавливается.
