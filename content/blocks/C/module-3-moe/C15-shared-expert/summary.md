## TL;DR

DeepSeekMoE добавляет к routed-экспертам **shared experts** — через них проходит каждый токен без
роутера, они берут на себя общее знание, а routed-эксперты специализируются. Эксперты узкие
(fine-grained: у DeepSeek-V3 256 экспертов шириной 2048, top-8), а первые слои — обычные dense FFN
(3 из 61). Отсюда «всего» и «активно»: FFN-часть V3 — ≈ 658B параметров, из них на токен ≈ 24B;
вся модель — 671B / 37B.

## Формула

$$y = \sum_{s} \text{FFN}^{\text{sh}}_s(x) + \sum_{j=1}^{k} w_j\,\text{FFN}_{e_j}(x),\qquad
\text{активно} = L_d\,3CF_d + L_m\big((k+S)\,3CF_e + EC\big)$$

## Формы тензоров

```
x [B,T,C] → routed MoE → [B,T,C] (+ logits [N,E]);  shared SwiGLU(S·F_e) → [B,T,C];  сумма → [B,T,C]
```

## Что поменялось относительно C13

К MoE-слою добавлен всегда активный shared expert; эксперты стали уже и многочисленнее; модель
перестала быть однородной — первые слои dense, остальные MoE.
