## TL;DR

Баг: eps прибавлялся после корня — `x / (sqrt(mean(x²)) + eps)` вместо
`x / sqrt(mean(x²) + eps)`. Обе формы защищают от деления на ноль и совпадают на обычных
активациях, но расходятся, когда mean(x²) сравним с eps. Код, совместимый с весами Llama, обязан
повторять формулу оригинала до мелочей.

## Формула

$$\text{верно: } \frac{x}{\sqrt{\operatorname{mean}(x^2)+\varepsilon}} \qquad \text{баг: } \frac{x}{\sqrt{\operatorname{mean}(x^2)}+\varepsilon}$$

## Формы тензоров

```
x [B,T,C] → mean(x², -1, keepdim) [B,T,1] → rsqrt(· + eps) [B,T,1] → x·inv_rms·weight [B,T,C]
```

## Что поменялось относительно C01

Ничего в архитектуре — урок про отладку: «почти совпадает» на типичных входах не значит
«правильно». Проверять нужно граничные режимы (маленький масштаб, большой eps, fp16).
